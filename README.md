## 目录结构

```
/
├── index.html                 跳转页 → 减重索引
├── 减重/                      科学减重（WL）项目需求单
│   ├── index.html             减重需求单独立索引（按模块分组）
│   ├── REQ-WL-STATUS-01-减重卡进行中状态与跨渠道购药判定.html
│   ├── REQ-WL-BASE-01-数据上报规范.html
│   └── REQ-WL-BASE-02-上线基线.html
└── _build/                    构建脚本（md → HTML）
```

每个 `.html` 都有同名 `.md` 作为**唯一内容源**。

## 命名规范

```
REQ-WL-{模块}-{序号}-{中文短名}
```

前缀 `WL` = 科学减重项目（后续其他项目使用自己的项目码）。

| 模块码 | 含义 |
| --- | --- |
| `STATUS` | 服务状态与卡片 |
| `RX` | 处方·购药·订单 |
| `PLAN` | 方案·评估·随访 |
| `EDU` | 科普·内容 |
| `AI` | AI 助理 |
| `BASE` | 规范与基线 |

- 序号在模块内从 `01` 递增，**不复用、不重排**
- 废弃单保留编号并标注「已作废」
- 中文短名 ≤12 字

## 需求单文档结构（6 节）

1. 背景与目标
2. 规则
3. 字段
4. 验收与上线要求
5. 依赖与风险
6. 待决策

**埋点不写在单子里**，统一登记在 `REQ-WL-BASE-01 数据上报规范`；
通用上线要求引用 `REQ-WL-BASE-02 上线基线`，单子里只写本单特有项。

## 怎么改

1. 改 `减重/*.md`（不要直接改 `.html`，会被覆盖）
2. 重新生成：

```bash
cd _build
npm install                 # 首次：安装 marked
npm run build               # md → HTML
npm run verify              # 可选：校验页面与关联链接
```

3. 提交并推送，`main` 分支会自动发布到 GitHub Pages。
