## 1. 规则

本单只定报告的页面结构。结论头与吸底分流见 `REQ-WL-PLAN-02`，正文文案怎么写见 `REQ-WL-PLAN-06`。

页面从上到下：

1. **结论头**：姓名、`性别 · 年龄 岁 · 身高cm / 体重kg · BMI X`，右侧「查看用户资料详情」图标；主标题 `减重建议`；三档刻度 `无需减重` / `需要减重管理` / `需要减重与慢病结合管理`；一句话结论。
2. **正文模块**：标题只用 `整体建议` / `饮食建议` / `运动建议` / `用药建议` / `就诊建议` 这五个，按结论选用，编号从 `01` 起按实际顺序排。
   - `整体建议` 固定四层：一段阶段描述 → 影响链图（生活方式 → 体重增加 → 指标异常 → 慢性疾病）→ 结论段 → 有依据的发现条目。影响链图是页面固定组件。
   - `用药建议` 默认收起，点 `查看详情` 展开；匹配度条在前、分析在后。
   - 模块之间还有一张 `体重管理小百科` 科普卡，页面固定组件。
3. **页脚固定声明**：`本页内容基于你填写的问卷与已关联的健康数据生成，为初步评估建议，不构成诊断和处方。`

- 正文文案由接口提供，页面只负责显示；加载中显示占位，请求失败显示错误态并能重试，不白屏。
- 模块内相邻块间距 10px，行高 21px；病名、指标用问卷勾选的原文。
- 顶栏「⋯」可切换患者、重新评估；返回回线上服务首页。Demo 里 14 位样例患者的内容直接写在页面里，正式上线换成接口数据。

## 2. 验收

- [ ] 结论头、三档刻度、一句话结论齐全；三档名称与单内一致
- [ ] 模块标题只用固定五个，编号按实际顺序排，没有自创标题
- [ ] `整体建议` 为四层结构；`用药建议` 默认收起、可展开
- [ ] 正文文案来自接口，页面没有固定文案；失败有错误态和重试
- [ ] 页脚声明原文一致
