# 减重评估报告：页面结构与正文

> 编号 `REQ-WL-PLAN-03` ｜ 项目：科学减重（WL）｜ 模块：方案·评估·随访 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[评估报告](https://lipulin222.github.io/health-subscription-demo/weight-management/Assessment-report/index.html) ｜ 埋点：`REQ-WL-BASE-01`

## 1. 规则

### 1.1 通用结构

页面从上到下：

1. **结论头**：姓名单独一行，下一行 `性别 · 年龄 岁 · 身高cm / 体重kg · BMI X`，右侧「查看用户资料详情」图标；三档刻度 `体型管理` / `体重管理` / `体重与慢病结合管理`，只点亮当前档；一句话结论。
2. **正文模块**：标题只用 `整体建议` / `饮食建议` / `运动建议` / `用药建议` 这四个，按报告选用，编号从 `01` 起按实际顺序排。
   - `整体建议` 四层：一段阶段描述 → 影响链图（生活方式 → 体重增加 → 指标异常 → 慢性疾病）→ 结论段 → 有依据的发现条目。
   - `用药建议` 默认收起，点 `查看详情` 展开；匹配度条在卡片头部常驻，分析在展开后显示。
3. **页脚固定声明**：`本页内容基于你填写的问卷与已关联的健康数据生成，为初步评估建议，不构成诊断和处方。`

- 品牌青色高亮只用于两处：`整体建议` 结论段里有依据的阶段短语、`用药建议` 里 `核心理由是：` 后另起一行的整段理由。其余正文不高亮。
- 模块内相邻块间距 10px，行高 21px；病名、指标用问卷勾选的原文。
- 顶栏返回先回上一页，没有上一页时回线上服务首页。

### 1.2 兜底页

结论头按通用结构，但不显示三档刻度；解读固定为 `你目前存在不适合使用减重药物的情况。体重管理可以先从非药物方式开始：调整饮食结构、增加日常活动、保持规律作息。`

正文只有一个 `01 生活方式建议` 模块，内容固定：

- `饮食`：三餐定时，主食与蛋白质搭配，减少含糖饮料，不要刻意节食。
- `活动`：从步行、拉伸开始，逐步增加时长和强度，量力而行。
- `作息`：固定入睡和起床时间，睡前减少屏幕使用。
- `体重记录`：每周固定时间称重一次，看趋势而不看单次数字。
- 末尾一段：`体重管理是长期过程，节奏比速度更重要。你的情况如有变化，可以重新评估，由医生判断是否适合用药。`

页脚按通用声明；吸底 `分享给亲友评估`、`咨询护士`（弹二维码浮层）。

### 1.3 体型管理页

结论头按通用结构，只点亮 `体型管理`；解读固定为 `你的体重在正常范围内，目前没有明确的用药指征。是否需要在体型上做进一步调整，可以结合自身需求和实际情况再评估。`

正文固定为三个模块：

1. `01 整体建议`：四段——① 体重和体脂分布共同决定健康风险和美观效果；② 腰围偏大一般是内脏脂肪较多，可预约内科医生面诊进一步评估；③ 体重正常但某个部位脂肪堆积属于皮下脂肪分布问题，想定向改善可做酷塑这类项目，是否适合需医美医生面诊评估；④ 卓正在内科和医美都有专业的医生团队，可以线上或到门诊咨询。
2. `02 饮食建议`：导语 `体重在正常范围时，饮食调整的目标是稳定，而不是减量。`；三条行动建议——`三餐定时，避免长时间空腹`：不规律进餐容易导致晚间加餐和一次吃过量；`含糖饮料和甜点控制频次`：这两类是额外热量最常见的来源，不需要完全戒掉；`看整体饮食质量`：蔬菜、蛋白质和主食搭配完整，比计算热量更容易长期坚持。
3. `03 运动建议`：导语 `想改善线条，力量训练的优先级高于有氧。`；三条行动建议——`每周两到三次力量训练`：深蹲、俯卧撑或器械都可以，重点覆盖腰腹与臀腿；`有氧保持常规量`：快走等中低强度即可，作用在心肺健康，不必为消耗额外加量；`训练日补充蛋白质`：足量蛋白质是肌肉合成的前提，摄入量可以按体重估算。

`整体建议` 里内科和医美后面的 `预约` 都进预约就诊页；点内科的预约默认锚定内科 tab，点医美的预约默认锚定医美 tab。页脚按通用声明；吸底 `邀请亲友评估`、`咨询护士`。
