## 1. 页面定位与整体结构

结营时给用户看的竖屏滚动式回顾页，页面标题 `科学减重 · 结营回顾`。整个页面在一个长滚动容器内，逐屏向上滑动观看：

- 顶部有一根细进度条，随滚动从 0% 涨到 100%。
- 右侧有一列竖排小刻度，一屏对应一个刻度；当前屏的刻度高亮；点击刻度平滑跳到对应屏；滚动经过深色/大图屏时，刻度自动换成反白样式。
- 每屏内容进入视口时渐显入场。
- 屏序：`01 / 07 序章（全屏图）` → `02 执行情况` → `03 体格指标` → `04 代谢指标` → `05 生活方式` → `06 随访记录` → `07 结论与建议`。

## 2. 各屏内容（文案以页面原文为准）

| 屏 | 内容 |
| --- | --- |
| 01 序章（深色全屏图） | 居中反白 Logo；`结营回顾报告 · {起始日期} — {结束日期}`；「体重变化」数字从 `0.0kg` 滚动到 `−8.6kg`（首次进入视口播放，约 1.3 秒，只播一次）；`体重 71.6 kg → 63.0 kg`；两行正文 `12 周，你按自己的节奏走完了。下面是这段时间留下的记录。`；底部 `上滑 ↓` 提示 |
| 02 执行情况 | `PART 01 · 执行情况` + 标题 `你坚持下来的 12 周` + 通栏配图 + 三格统计：`78次 记录打卡` / `12次 按时用药` / `3次 线下复查` + 两行正文 `78 次记录、12 次用药、3 次复查。这些数字不是我们统计的，是你一次次做出来的。` |
| 03 体格指标 | `PART 02 · 体格指标` + 标题 `身体正在回应你` + 通栏配图 + 三行起止对比：体重 `71.6 → 63.0 kg（−8.6）` / 腰围 `84.8 → 78.5 cm（−6.3）` / 体脂率 `30.2% → 24.6%（−5.6）` + 两行正文 |
| 04 代谢指标 | `PART 03 · 代谢指标` + 标题 `看不见的地方，也变好了` + 通栏配图 + 三行变化：甘油三酯 `2.3 → 1.2 mmol/L（已达标）` / 空腹血糖 `偏高 → 正常（已达标）` / 代谢状态 `内脏脂肪偏高 → 风险降低（已改善）` + 两行正文 |
| 05 生活方式 | `PART 04 · 生活方式` + 标题 `变化的不只是体重` + 通栏配图 + 三条图标行：`精力回来了`（午后不再犯困，一天忙下来还有余力）/ `和食物的关系松开了`（三餐规律，不再靠吃东西去疏解情绪）/ `心里有底了`（体重有涨有落，你知道这是正常的）+ 收束句 `这些习惯，比掉下去的 8.6 公斤更留得住。` |
| 06 随访记录 | `PART 05 · 随访记录` + 标题 `这一路，你不是一个人` + 四条时间线：第 1 周 `完成评估，开始用药` / 第 4 周 `身体适应，剂量上调` / 第 8 周 `线下面诊，指标正常` / 第 12 周 `达成目标，转入维持期`（各带一句说明）+ 收束句 |
| 07 结论与建议 | `PART 06 · 结论与建议` + 标题 `接下来，把成果稳住` + 通栏配图 + 三条建议：指标达标可进入维持期 / `每 2 周称重 1 次、每月复查 1 次就够了，不用每天紧张` / 体重回升或身体不舒服随时联系随访医生 + **`分享成就` 按钮** + 副文案 `保存到相册，或分享给在乎的人` |

页脚（三行小字）：数据来源 `数据来自你的打卡记录与 {复查日期} 复查结果`；审核行 `内容审核 {审核医生} · {科室职称} · 更新于 {更新日期}`；免责声明 `本页为健康管理服务记录，不构成诊疗建议，具体请以医生面诊意见为准。`。

## 3. 分享成就（链接分享 + 分享海报）

07 屏点 `分享成就` 后提供两种分享方式：

| 方式 | 行为 |
| --- | --- |
| **生成分享海报** | 按分享卡模板（底图 `share.jpg`）把回顾关键数据（减重公斤数、起止体重、日期区间、品牌信息）渲染成一张分享卡图片，保存到手机相册，用户可自行发朋友圈 / 私聊 |
| **链接分享** | 走系统分享面板分享本页链接；不支持系统分享的浏览器回退为复制链接，toast `链接已复制`，失败兜底 `复制失败，请长按地址栏复制`，再不支持提示 `当前浏览器不支持分享` |

- 海报上不出现：手机号、档案详情、诊断结论等隐私与医疗敏感信息，只放回顾页已有的汇总数据与品牌元素。
- 演示环境为简化桩：点 `分享成就` 按钮文字变为 `分享卡已生成，可在相册查看` 并禁用；生产环境按上表两种方式实现（方式选择形式——底部弹层 / 双按钮，待产品确认）。
