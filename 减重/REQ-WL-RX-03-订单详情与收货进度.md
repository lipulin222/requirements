## 1. 规则

### 1.1 页面与进度

- 页面标题 `订单详情 · 体重管理首诊套餐`，顶栏标题 `订单详情`。本页在现有订单详情页上改造，不是新做页面。
- 五步进度：`已支付 → 医生评估 → 填写物流 → 发货 → 完成`。单向流程，完成后进下一环节，不回退。直接进入时默认停在 `医生评估`；演示用地址参数切换环节，正式上线由订单状态决定。
- 进度节点：已完成是品牌色实心圆加白色对勾；当前是白底品牌色描边圆加内点、文字品牌色；未到是灰底圆加序号、文字灰。连接线已走完段品牌色、未走段灰。点 `已支付` 提示 `已支付环节已完成`。演示可点节点切环节，正式上线不开放点击。
- 进度条下方是各环节都有的**订单信息卡**：首行 `商品` + `体重管理首诊套餐（【穆峰达】替尔泊肽注射液）`；点 `展开订单信息` 显示 `订单编号` / `支付金额` / `支付方式` / `支付时间` 四行，再点变 `收起订单信息`。

### 1.2 各环节内容

| 环节 | 内容 |
| --- | --- |
| 医生评估 | 患者信息卡（头像、`患者信息`、`女 | 32岁`，姓名 / 身高 / 体重（购药前）/ BMI）+ 居中两行：`医生正在结合你的情况评估方案，预计 1 个工作日内完成。`、`完成后你会收到公众号通知和短信。` |
| 填写物流 | 物流卡三行：收件人 / 收货地址 / 希望收货时间；没填显示灰字 `待完善`，整张卡可点进填写页。下方提示 `药品需冷链配送，请完善收货信息以确保顺利签收；收货后请立即将药品放入冰箱冷藏（2–8℃）。` |
| 发货（待发货） | 居中一行 `根据你的要求，药品将于{发货日期}发货。` |
| 发货（已发货） | `药品已于{发货日期}发货。` + 居中 `物流单号 {单号}` 带复制按钮；复制成功 `物流单号已复制`，失败 `复制失败，请长按单号复制` |
| 完成 | `药品已于{发货日期}发货并完成收货。` + 同样的单号行 |

- 全页没有吸底按钮。发货日期与物流单号正式上线由接口给。
- 填写收货信息页：收货人、手机号、收货地址、希望收货时间（选连续两天），按钮 `确认收货信息`；提交后回订单详情，物流卡回显实值。
- 顶栏「更多」提示 `药品将由冷链配送，收货后请立即冷藏（2–8℃）`；返回回线上服务首页。
