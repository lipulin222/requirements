## 1. 这张卡什么时候出现

用户在用药中（条件同 `REQ-WL-STATUS-06`），并且后台配置的某条提醒命中了触发条件——卡片在卡头下方多出一张提醒卡，其余内容和进行中状态一致。

提醒不只有续药，也可能是复查、饮食、运动、问卷等任何后台配置的提醒。

## 2. 卡片上显示什么（自上而下）

健康订阅区的头图区与专项标签行见 `REQ-WL-STATUS-02`。

1. **卡头**：与进行中状态一致（图标 + `体重管理` + `猜你想问 · 问题 ›`，问题轮播）。
2. **提醒卡**（浅橙色底、圆角块）：
   - 第一行：橙色铃铛图标 + 橙色加粗标题（例：`续药提醒`）。
   - 第二行：橙色正文，一句话讲清「发生了什么 + 建议怎么做」。
   - 同一时间只显示一张提醒卡。
3. **体重数据块**：与进行中状态一致（大号已减重量 + 右侧圆形画笔按钮 + `已坚持 N 天 · 体重 X → Y`）。
4. **底部两个按钮**，并排等宽、大圆角：
   - 左：`AI减重助理`（浅青底 + 青色描边 + 青色文字）
   - 右：`查看更多`（青色实底 + 白字）

## 3. 后台可配置的三件事

提醒卡的内容不在端上写死，全部由后台配置：

| 配置项 | 说明 |
| --- | --- |
| 触发逻辑 | 什么条件命中就展示这条提醒（例：药品剩余量不足两周、距上次复查超过 N 周、距上次记录体重超过 N 天） |
| 文案 | 提醒标题 + 正文一句话，运营可改 |
| 展示次数 | 这条提醒最多展示几次；达到次数后不再展示 |

## 4. 点击与跳转

| 位置 | 点击后去哪 |
| --- | --- |
| 提醒卡 | 该条提醒配置的目标页面（例：续药提醒进支付页） |
| 卡头第二行（`猜你想问 · 问题 ›`） | 科普知识库，定位到当前这条问题对应的文章 |
| 体重块右侧圆形画笔按钮 | 跳到现有的录入体重页面 |
| `AI减重助理` | AI 减重助理对话页，带用药中场景，并带上当前是第几周、整个疗程 24 周 |
| `查看更多` | 查看更多聚合页——里面有相关订单、评估报告、减重月报三个入口（见 `REQ-WL-RX-06`） |
