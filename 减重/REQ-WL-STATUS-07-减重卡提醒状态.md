## 1. 规则

### 1.1 什么时候出现

用户在用药中（条件同阶段③），并且命中了后台配置的提醒时，卡片在数据区上方多一张提醒卡，其余内容和阶段③一样。Demo 默认显示 `续药提醒`；提醒卡右上角的图标可以逐条切换，8 条提醒都能看到。

### 1.2 卡片上显示什么（自上而下）

1. **卡头**：图标 + `体重管理` + `猜你想问` 轮播。本阶段 4 条：`什么时候可以停药` / `结束之后怎么维持住` / `复查都看哪些指标` / `哪些情况要马上联系医生`。共用规则见 `REQ-WL-STATUS-04` 第 4 节。
2. **提醒卡**：浅橙底圆角块，第一行橙色铃铛图标 + 橙色加粗标题，第二行一句话正文。同一时间只显示一张，整张卡可点，跳该条提醒的目标页面。
3. **体重数据块**：和阶段③一样，大号已减重量 + 右侧圆形画笔按钮 + `已坚持 N 天 · 体重 X → Y`。
4. **底部两个按钮**：左 `询问护士`，右 `查看更多`。

### 1.3 8 条提醒

| # | 标题 | 正文 | 点击去向 |
| --- | --- | --- | --- |
| A1 | 随访提醒 | 体重下降偏快，建议预约面诊一次。 | 疗程随访评估 |
| A2 | 随访提醒 | 近三周体重变化很小，建议做一次体成分检测。 | 疗程随访评估 |
| A3 | 问卷提醒 | 到第 12 周了，建议做一次复评问卷。 | 疗程随访评估 |
| B1 | 饮食提醒 | 食欲下降期更要吃够营养，建议查看饮食方案。 | 减重评估报告 |
| B2 | 运动提醒 | 加些力量训练，可以减少肌肉流失。 | 减重评估报告 |
| C1 | 续药提醒 | 药品预计两周内消耗完，建议续药或复诊。 | 疗程随访评估（默认显示） |
| C2 | 面部评估提醒 | 体重下降过快，建议皮肤科面诊评估面部状态。 | 疗程随访评估 |
| C3 | 运动康复提醒 | 运动中有疼痛不适，建议到院运动康复面诊。 | 疗程随访评估 |

- 标题、正文和触发条件由后台配置，运营可改，页面只负责显示。多条同时命中时只显示一条，优先级由后台定。
- 续药提醒出现后，只要还没有续药下单记录就一直显示；完成续药下单后消失。

### 1.4 点击与跳转

| 位置 | 点击后去哪 |
| --- | --- |
| 提醒卡 | 该条提醒的目标页面（见 1.3） |
| 卡头第二行（`猜你想问 · 问题 ›`） | 科普知识库里当前这条问题对应的文章 |
| 体重块右侧圆形画笔按钮 | Demo 里提示 `正在打开数据记录`；正式上线进录入体重页 |
| `查看更多` | 查看更多聚合页（评估报告、减重月报、相关订单） |
