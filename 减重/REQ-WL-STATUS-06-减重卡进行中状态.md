## 1. 这张卡什么时候出现

用户有首诊套餐支付记录，并且有拿药 / 收货记录，还在处方药程内（见 `REQ-WL-STATUS-01`），由服务端判定进入本阶段。

## 2. 卡片上显示什么（自上而下）

健康订阅区的头图区与专项标签行见 `REQ-WL-STATUS-02`。

1. **卡头**：
   - 左侧浅绿色方形圆角图标（体重秤图形）。
   - 右侧两行：
     - 第一行：`体重管理`（大号、深色加粗）
     - 第二行：`猜你想问`（青色）+ `· ` + 当前问题（深灰）+ 右侧箭头 `›`
   - 第二行的问题每 2.6 秒换一条，循环播放，前缀不动；条数与文案由后台知识库对应分类下发，端上不写死。
2. **体重数据块**，分两种情况：
   - **基线体重 = 用户填写首诊问卷时登记的体重**（不是首次录入的体重）。首次展示、后续计算都用它做起点。
   - 已经有体重更新记录：左侧大号数字 = **当前最新体重 − 基线体重** 的差值，展示形如 `−3.2kg`（减了多少）；右侧一个浅灰圆形按钮，里面是画笔图标（点击跳到现有的录入体重页面）；数字下方一行 `已坚持 28 天 · 体重 71.6kg → 68.4kg`（起点=基线体重，终点=当前最新体重，天数、数值取真实数据）。
   - 还没有任何体重更新记录：大号数字直接显示基线体重 `71.6kg`，右侧同样是圆形画笔按钮；下方一行 `每周更新体重记录，更好追踪身体变化。`
   - 两种情况都不显示 `−0kg` 这类没有意义的数字。
3. **底部按钮组**：左 `询问护士`（浅色次按钮）+ 右 `查看更多`（青色实底 + 白字，大圆角）；有待办（生成月报 / 新月报）时 `查看更多` 按钮右上角挂红色角标，规则见 `REQ-WL-RECORD-01`。

## 3. 猜你想问（本阶段）

轮播的问题文案**从后台知识库对应的分类里随机拉取**，不在端上写死：

- 本阶段对应知识库中的相应分类，分类与文章的对应关系由后台配置。
- 运营在知识库里增删文章后，轮播内容随之更新。
- 每条问题与其对应文章的链接一并下发，点击进当前这条问题对应的文章。

卡头与猜你想问的共用规则（图标 + `体重管理` + 2.6 秒轮播 + 深链文章）见 `REQ-WL-STATUS-04` 第 4 节。

## 4. 点击与跳转

| 位置 | 点击后去哪 |
| --- | --- |
| 卡头第二行（`猜你想问 · 问题 ›`） | 科普知识库，定位到当前这条问题对应的文章 |
| 体重数据块（大号数字与下方一行，整体可点） | 现有的体重趋势页面 |
| 体重块右侧圆形画笔按钮 | 跳到现有的录入体重页面 |
| `查看更多` | 查看更多聚合页——里面有相关订单、评估报告、减重月报三个入口（见 `REQ-WL-RX-06`） |

## 5. 验收

- [ ] 已减重量的起点为首诊问卷登记的体重（基线），展示值为最新体重减基线的差值（形如 `−3.2kg`）
- [ ] 下方一行为 `已坚持 N 天 · 体重 基线 → 最新`，天数与数值取真实数据
- [ ] 无体重更新记录时显示基线体重与引导文案，不出现 `−0kg`
- [ ] 点击体重数据块跳到现有的体重趋势页面；右侧圆形画笔按钮跳到录入体重页面
- [ ] 有月报待办时 `查看更多` 按钮挂红点，文案与 RECORD-01 一致
- [ ] 猜你想问文案从后台知识库对应分类随机拉取，点击进当前问题对应的文章
- [ ] 右下角主按钮为 `查看更多`，点击进入含订单 / 评估报告 / 减重月报的聚合页
- [ ] App 与小程序一致

## 6. 开启日（stage⑥，进入③的前置仪式屏）

已支付、已拿药，但还没记录减重第一天的用户，首次进入时先显示本仪式屏（服务端判定，见 `REQ-WL-STATUS-01` 阶段表）：

- 卡头标题改为 `减重旅程开启！`，猜你想问沿用阶段①的轮播内容。
- 4 段进度轨道：`适应期 → 剂量调整 → 优化期 → 维持期`，点亮第 1 段。
- 陪伴句：`很高兴你关注自己的健康。接下来 24 周，卓正会用专业和关怀，陪你顺利实现减重目标。`
- 全宽通栏按钮 `记录第一天`，下方灰字 `建议以第一次打针日期作为减重第一天`。
- 点按钮呼起系统日期选择器；选定后 toast `已记录，{日期} 为你的减重第 1 天`，卡片进入③的「还没有体重记录」初始态（见第 2 节），此后不再出现本仪式屏。
