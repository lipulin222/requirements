2. 定稿全文（一字不改）

本同意书适用于【平台/机构全称（广州卓祥医疗门诊部有限公司）】（以下简称“平台”）提供的科学减重管理服务。请在填写问卷、接受诊疗前完整阅读全部内容；如有疑问，请在签署前向客服咨询。

一、服务模式与首诊/复诊规则

  1. 本人知悉并确认：本平台减重管理服务仅针对复诊患者提供互联网诊疗。根据《互联网诊疗管理办法（试行）》《互联网诊疗监管细则（试行）》等规定，互联网诊疗不得对首诊患者开展诊疗活动。首次就该减重相关事项寻求诊疗的，或平台根据问卷信息判断属于首诊情形的，本人在获得实体医疗机构明确诊断后，方可凭有效病历资料申请线上复诊服务。
  2. 本人理解，线上复诊的前提是本人能够提供实体医疗机构出具的明确诊断的病历资料（如门诊病历、诊断证明、检查报告等）。无法提供上述资料，或平台/医生判断不符合复诊条件的，平台有权拒绝提供线上诊疗服务，并建议本人线下就医。因本人未能提供合格复诊资料或首诊导流安排所产生的诊疗延迟，不视为平台或医生的过错。
  3. 本人确认：健康智能体在问卷阶段生成的任何分层、提示或建议，仅用于信息收集、分诊引导和医生参考，不构成诊断结论或用药建议，本人不会将其作为自行用药或自我治疗的依据。

二、信息真实性声明

  1. 本人已如实、完整填写健康问卷及相关资料，包括但不限于身高、体重、BMI、既往病史、用药史、过敏史、家族史、妊娠及哺乳情况、目前正在使用的药物与保健品等。
  2. 本人特别确认：身高、体重等由本人自述或自行测量的数据，其真实性、准确性由本人负责。 本人理解线上场景下医生无法直接进行体格测量，BMI等关键指标的计算完全依赖本人提供的数据。本人不会虚报、少报体重或瞒报身高，不会以“目标体重”替代“当前实际体重”填写。 因自述数据不实导致医生评估偏差、处方不当或减重效果未达预期的，相应后果由本人承担。
  3. 本人确认所填信息真实、准确，不存在虚假、隐瞒或遗漏。医生基于本人所提供信息作出的评估、诊断、处方及用药方案，其合理性与安全性以信息真实为前提。信息不实可能直接影响诊疗的安全性与有效性，本人已知悉并自愿承担由此产生的风险。
  4. 在服务期间，如本人的体重、健康状况、用药情况等发生变化，将及时如实告知医生。本人不会依据过时或未更新的自述数据继续接受线上诊疗服务。

三、医生独立诊疗与处方授权

  1. 本人同意，平台执业医生在符合法律法规及互联网诊疗相关规范的前提下，结合本人提交的问卷、资料、问诊沟通内容及必要的检查检验结果，独立作出专业判断，评估本人是否适合接受减重治疗。经评估适合的，医生可以开具处方（可能包括减重药物，含注射类药物），并提供饮食、运动及行为管理指导。
  2. 本人知悉并确认：平台使用的健康智能体及任何人工智能工具，其功能限于问卷信息收集、结构化呈现、分诊提示和随访提醒等辅助性用途。人工智能工具的输出不具有诊断结论或处方建议的效力，不得替代执业医生的专业判断，亦不得冒用、替代医师本人提供诊疗服务。任何减重药物的处方，均须由接诊医师本人基于对本人情况的独立评估后开具。
  3. 本人理解处方是否开具由医生依法独立决定，并非本人必然获得。医生有权要求本人补充信息、检查检验或既往诊断、病历资料，有权调整或拒绝开具药物、建议线下就医，或终止本服务。医生依据平台智能体提示或问卷结果所作出的“建议线下就医”“暂不适宜线上诊疗”等判断，属于依法履行诊疗义务的行为，不构成对本人服务请求的无正当理由拒绝。
  4. 本人理解线上问诊无法替代线下面对面的体格检查，医生的判断在很大程度上依赖本人提供信息的真实性（如身高、体重），并同意按医生要求提供真实的测量数据、检查报告及既往诊疗资料。

四、减重治疗的效果与风险告知

  1. **需要长期管理。**肥胖可能是一种需要终身管理的慢性状态，往往需要长期调整饮食习惯并做出持久的行为改变，才能取得并维持理想的治疗效果。部分患者在减量或停药后体重可能反弹。
  2. **效果因人而异，无法保证。**减重效果受体质、合并疾病、饮食运动依从性、用药反应等多种因素影响。本人理解治疗过程可能达不到本人或他人的预期，平台和医生无法承诺特定的减重幅度或时间。
  3. **可能出现不良反应。**任何药物治疗均可能带来风险。常见不良反应包括恶心、呕吐、腹泻、便秘、腹胀、食欲下降、头晕乏力、注射部位反应等；少数情况下可能出现严重不良反应，如急性胰腺炎、胆囊相关疾病、严重过敏反应、低血糖（尤其在合并使用降糖药物时）等，极少数情况下可能危及生命。具体以所用药品说明书为准。
  4. **方案可能调整。**医生可能根据本人的反应和检查结果调整剂量、更换药物或停药。
  5. **不治疗也有风险。**超重或肥胖会增加高血压、糖尿病、心血管疾病、睡眠呼吸暂停综合征、关节疾病等风险，本人已权衡治疗获益与风险。
  6. 本人已充分阅读并理解上述内容，知悉相关风险；如有疑问，已有机会在签署前向医生或客服咨询。

五、本人的配合义务

  1. 按医嘱规范用药，不自行增减剂量、变更用法或与其他药物、保健品叠加使用；按要求保存药品，不将药品转让、转售或赠予他人。
  2. 按要求进行随访、记录体重等指标，并配合完成所需的检查检验。本人理解，体重等指标的规范记录是医生评估疗效和调整方案的基础，无正当理由拒绝配合随访或检查，可能导致医生无法继续安全有效地提供线上服务。
  3. 如出现严重或持续不适（如剧烈腹痛、持续呕吐、过敏、心慌心悸、明显低血糖症状等），立即停止用药，并及时就医、联系医生。
  4. 如计划怀孕、已怀孕或正在哺乳，必须在第一时间告知医生。

六、责任承担与免责

  1. 自述数据不实的责任。 如因本人提供虚假、不完整或有意隐瞒的信息（包括但不限于虚报身高、体重、BMI，隐瞒病史、过敏史、禁忌症、用药史或妊娠哺乳状态），导致诊断、处方或用药建议与本人实际情况不符，由此产生的不良后果及相关责任，由本人自行承担，平台及医生在法律允许的范围内不承担责任。
  2. 首诊导流与拒绝线上诊疗的责任。 本人理解并同意：平台依据法律法规及问卷评估结果将首诊患者引导至线下医疗机构，或在本人不符合复诊条件时拒绝提供线上诊疗服务，系履行合规义务的行为。因首诊导流、复诊条件审核或线上服务终止所造成的诊疗时间延迟或不便，不构成平台或医生的违约或过错，但平台应在合理范围内提供必要的指引和说明。
  3. AI辅助工具使用相关的责任。 本人确认不会将平台健康智能体、问卷结果或任何AI生成内容作为自我诊断、自行购药或自行调整用药的依据。如本人未经执业医生确认，自行依据智能体输出或问卷提示采取用药、停药或其他干预措施，由此产生的后果由本人自行承担，平台及医生不承担责任。
  4. **未遵医嘱的责任。**如因本人未按医嘱用药、擅自调整剂量、与其他药物叠加使用或未及时就医造成的后果，由本人自行承担相应责任。
  5. **效果未达预期的责任。**本人理解减重效果未达预期本身，不构成平台或医生的过错，不作为要求退款、赔偿的当然理由（退款规则以服务协议约定为准）。
  6. 本条款不免除平台、医生因故意或重大过失、诊疗过错等依法应承担的责任。

七、个人信息处理同意

本人同意平台为提供减重管理服务、完成问诊与处方、随访及安全监测的目的，收集和处理本人的个人信息，包括身份信息、联系方式以及身高体重、病史、用药史等敏感个人信息（健康信息）。本人知悉，平台健康智能体在问卷收集和分析环节会接触上述信息，但相关信息的使用限于本同意书载明的目的和《隐私政策》约定的范围。平台将依法保护上述信息，具体规则见《隐私政策》。
