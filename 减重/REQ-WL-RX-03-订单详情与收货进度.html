1. 页面与进度环节

页面与顶栏标题均为 减重套餐流程。进度环节为五步：

已支付 → 医生评估 → 填写物流 → 发货 → 完成

  • 单向流程：每个环节只有「进行中」，完成后进入下一环节，不回退。
  • 用户进入本页时停在哪个环节，由订单状态接口决定（真实环境）；演示环境用地址参数切换各环节预览。
  • 「已支付」永远是已完成状态，点击它提示 已支付环节已完成。

进度条渲染：

节点态 渲染
已完成 品牌色实心圆 + 白色对勾
当前 白底品牌色描边圆 + 内点，文字品牌色加粗
未到 灰底圆 + 序号 3/4/5，文字灰
连接线 已走完段品牌色，未走段灰

进度条节点可点击切换环节仅为演示辅助，生产环境不开放点击。

2. 各环节内容

2.1 医生评估（进行中）

页面居中两行文字，无卡片、无吸底按钮：

  • 医生正在结合你的情况评估方案，预计 1 个工作日内完成。
  • 完成后你会收到公众号通知和短信。

2.2 填写物流（进行中）

自上而下：物流卡 + 患者信息卡 + 页脚提示 + 吸底按钮。

  • 物流卡（上）：三行——收件人 / 收货地址 / 希望收货时间。未填写时显示灰字 待完善；已填写显示实值，收件人一行显示 姓名 手机号。整张卡可点击，进入收货信息填写页（现成页面，无需开发），卡右侧有箭头示意。
  • 患者信息卡（下，独立卡片，只读）：头部为头像 + 患者信息 + 性别 | 年龄。行：姓名 / 身高 / 体重（标注 购药前）/ BMI / 腰围 / 过敏史（药物过敏、食物过敏、其他过敏）。由健康档案接口带入。
  • 页脚提示：药品需冷链配送，请完善收货信息以确保顺利签收；收货后请立即将药品放入冰箱冷藏（2–8℃）。
  • 吸底按钮：未填写 去填写收货信息 / 已填写 修改收货信息，均进收货信息填写页。
  • 填写结果回传后，本页物流卡实时回显实值（演示环境暂存本机，真实环境以服务端为准）。

2.3 发货（进行中）

按发货状态分两种展示，均为居中文字：

  • 待发货：根据你的要求，药品将于{发货日期}发货。
  • 已发货：药品已于{发货日期}发货。 + 居中一行 物流单号 {单号} 带复制按钮；点击复制单号，成功 toast 物流单号已复制，失败兜底 toast 复制失败，请长按单号复制。

发货日期与物流单号由服务端下发，前台不写死。

2.4 完成

页面居中：药品已于{发货日期}发货并完成收货。 + 物流单号行（同 2.3，可复制）。

除「填写物流」环节外，其他环节不显示吸底按钮。

3. 通用交互

  • 顶栏「更多」按钮：toast 药品将由冷链配送，收货后请立即冷藏（2–8℃）。
  • 顶栏返回：有浏览历史时正常返回；无历史时回线上服务首页。

4. 验收

  • 页面与顶栏标题为 减重套餐流程
  • 五步顺序 已支付 → 医生评估 → 填写物流 → 发货 → 完成；直接进入时默认停在「医生评估」
  • 「已支付」点击提示 已支付环节已完成
  • 医生评估环节只有居中提示两行，无卡片、无吸底按钮
  • 填写物流环节：物流卡三行空态 待完善，患者信息卡只读，页脚提示原文一致，吸底按钮出现
  • 已填写后物流卡回显实值，吸底按钮变 修改收货信息；点卡片和点按钮都进填写页
  • 发货环节：待发货 / 已发货文案正确；已发货有单号行，复制成功与失败的提示都正确
  • 完成环节文案与单号行正确
  • 除填写物流外，其他环节不出现吸底按钮
  • 顶栏「更多」提示原文一致
