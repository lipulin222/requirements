# 减重卡 · 维持期状态（一个疗程结束）

> 编号 `REQ-WL-STATUS-08` ｜ 项目：科学减重（WL）｜ 模块：服务状态与卡片 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[线上服务页](https://lipulin222.github.io/online-health-care/weight-companion-ui/online-service.html?stage=5) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 这张卡什么时候出现

用药结束（支付成功日 + 处方药程）满 1 周，且后台数据没有更新（见 `REQ-WL-STATUS-01`）。

维持期卡片置顶 1 个月，1 个月后卡片回到科普状态。

## 2. 卡片上显示什么（自上而下）

（本状态的界面为暂定稿，后续可能调整。）

1. **卡头**：左侧 `体重管理`（大号、深色加粗）；右侧 `更多 ›`。
2. **成果区**（浅色底 + 放射光效与彩色纸屑装饰）：
   - 一个大虚线框，左右各一支麦穗装饰，中间是橙色大字 `减重8.6kg`（数字取真实值）。
   - 框下方一行灰字 `71.6kg → 68.4kg · 24 周`（起始体重 → 结束体重 · 疗程周数）。
3. **三个指标**，横排等分，相邻之间浅灰竖线分隔，每个指标上为大号数字、下为灰字说明：
   - `78次` — `打卡`
   - `-9.5cm` — `腰围`
   - `3次` — `复查`
4. **底部一个通栏按钮**：`打开回顾`（青色实底 + 白字，大圆角）。

本状态没有 AI 助理按钮，也没有单独的查看更多按钮。

## 3. 点击与跳转

| 位置 | 点击后去哪 |
| --- | --- |
| 卡头右侧 `更多 ›` | 查看更多聚合页——里面有相关订单、评估报告、减重月报三个入口（见 `REQ-WL-RX-06`） |
| `打开回顾` | 结营回顾页 |

## 4. 验收

- [ ] 卡头左侧为 `体重管理`，右侧为 `更多 ›`
- [ ] 成果区显示 `减重<数字>kg`、左右麦穗与虚线框，下方显示起止体重与疗程周数
- [ ] 三个指标顺序为 打卡 / 腰围 / 复查，数值取真实记录，缺数据则不显示该格
- [ ] 底部只有一个通栏按钮 `打开回顾`
- [ ] `更多 ›` 进聚合页，`打开回顾` 进结营回顾页
- [ ] 置顶 1 个月后卡片回到科普状态
- [ ] App 与小程序一致
