1. 规则

1.1 什么时候进

  • 减重卡的提醒卡、聚合页评估报告列表的 新增评估，以及首页阶段 3 及以后的评估入口。
  • 首页阶段 1 的 快速评估 进首诊问卷，不进本页。

1.2 答题

一屏一题，共 10 题，顺序固定。顶部 第 X / 10 题 与 约 2 分钟，进度条可点回已答过的题；按钮 上一题 / 下一题 / 提交评估，选项题没选时提示 先选一项，再继续。体重类数字题可以留空，按 未填写 处理。

# 题目 选项
1 你现在处于用药的哪个阶段 适应期（1–4 周）/ 第一次上调后（5–8 周）/ 剂量优化期（9–12 周）/ 维持期（13 周以上）/ 已经停药 / 不确定
2 和开始用药时相比，你的体重变化 填开始、现在两个数字，自动算变化
3 你的腰围和开始相比 明显小了（5cm 以上）/ 小了一点（不到 5cm）/ 没变化 / 反而大了 / 不确定
4 这段时间有没有出现不舒服（多选） 恶心、没胃口 / 便秘 / 胃胀、反酸 / 乏力、头晕 / 注射部位红肿 / 基本没有 / 不确定
5 这些不舒服对你的影响 有点影响，但能坚持 / 影响进食或日常生活 / 已经影响工作或睡眠 / 没有不舒服 / 不确定
6 这段时间你的用药执行情况 完全按计划，没有漏 / 漏过 1 次 / 漏过 2 次以上 / 自己调过剂量 / 不确定
7 饮食和运动的配合做得怎么样 一直在做，比较规律 / 做了一些，不太规律 / 基本没顾上 / 不确定
8 最近做过哪些复查（多选） 体重、腰围等基础指标 / 血糖 / 糖化血红蛋白 / 血脂 / 肝肾功能 / 都还没查 / 不确定
9 这段时间你的饮食情况（多选） 三餐规律，基本按医生建议吃 / 经常外食、外卖为主 / 口味偏重（油炸、甜饮料）/ 吃得很少，常常吃不下或顾不上 / 应酬多，会喝酒 / 不确定
10 有没有出现下面这些情况（多选，安全题） 持续呕吐，吃什么吐什么 / 腹痛，且向背部放射 / 皮肤或眼白发黄 / 起疹、脸肿、喘不上气 / 以上都没有

1.3 结果页

  • 提交后进结果页，标题 评估结果，分警示页和建议页两类。
  • 客观摘要行：当前阶段、体重变化、腰围变化、不适影响、用药执行、饮食情况；没填的显示 未填写。下面 返回修改答案 可回问卷改。
  • 底部 线上续药 → 支付页；预约面诊 → 预约就诊页。
  • 页脚：如填写有误，可返回修改后重新评估。 + 本页内容基于你填写的问卷生成，为初步评估建议，不构成诊断和处方。
  • 顶栏「⋯」可切换 线上续药（计划内） / 预约面诊（需医生评估） 两种预览分支；返回回线上服务首页。
  • 答案留存供医生端查看；提交后 14 天内首页按「线上续药」口径展示。

2. 验收

  • 三个入口均可进入；首页 快速评估 不进本页
  • 10 题一屏一题、题干与选项与单内一致；进度条可回已答题修改
  • 体重数字题留空可继续，摘要里显示 未填写
  • 安全题命中时给警示结论，不给用药剂量建议
  • 结果页摘要、页脚声明、线上续药 / 预约面诊 去向齐全
