## 1. 规则

### 1.1 页面结构（自上而下）

| 区块 | 规则 |
| --- | --- |
| 入门卡 | 1 张置顶大卡，取用户当前阶段第一篇，点击进文章详情 |
| 你可能想看 | 按用药阶段取 3–4 篇：早期取 W01–W06，中期取 M01–M06；阶段判定依赖 `REQ-WL-STATUS-01` 的月序，接口就绪前按「早期」兜底 |
| 按主题找 | 饮食 / 运动 / 用药 / 复查分组入口，点击 toast `内容整理中，敬请期待`（二期承接） |
| 全部内容 › | 同上占位（二期） |
| 吸底 | `快速减重评估` → PLAN-01（`?state=new`） |

- 文章卡不带发布时间。
- 首页消费字段：标题、导语（≤30 字，不写阅读指引）、封面（可选）、所属阶段；接口由技术方案定。
- 下架文章即时消失，列表重排不留空位。

## 2. 验收

- [ ] 入门卡为当前阶段第一篇
- [ ] 「你可能想看」按阶段取数，早期 / 中期用户列表不同
- [ ] 无封面文章渲染纯文字卡，无破图
- [ ] 二期入口点击 toast 原文一致，不 404
- [ ] 吸底按钮带新客态跳 PLAN-01
