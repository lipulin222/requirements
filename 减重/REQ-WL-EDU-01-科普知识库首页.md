## 1. 规则

### 1.1 页面定位与数据来源

- 页面与顶栏标题为 `减重科普`。
- **全部科普文章都存在知识库里，页面从知识库拉取**：端上不放固定的文章列表；入门卡、「你现在可能想看」、主题分组都从知识库接口按用户阶段实时取文章。知识库内容会持续迭代更新，运营增删改文章后页面随之变化，不需要发版。知识库内容与结构由望时负责维护提供，接口与字段由开发对接（见《待确认问题清单》C-04）。

### 1.2 页面结构（自上而下）

| 区块 | 规则 |
| --- | --- |
| 入门卡 | 1 张置顶大卡：角签 `入门第一课` + 标题 `什么是体重管理？` + 副文 `不是饿肚子，也不靠意志力硬扛。它做的是一件更本质的事——把你身体里本来就有的「吃饱了」信号找回来，并且留得久一点。` + 文字链 `开始了解 ›`；点击进对应文章 |
| 你现在可能想看 | 标题 `你现在可能想看`；按用户阶段取 3 篇文章卡（购前 / 用药中 / 维持期各一组），每张卡显示标题 + 导语 |
| 按主题找 | 标题 `按主题找`，右侧文字链 `全部内容 ›`；4 个分组入口：`认识减重`（适合谁 · 效果 · 流程）/ `用药与安全`（常见反应 · 漏服）/ `日常生活`（怎么吃 · 怎么动）/ `过程管理`（平台期 · 复查 · 维持）；每组卡上有 `N 篇` 计数，点击进该分组文章列表 |
| 全部内容 › | 进全部文章二级列表页 |
| 吸底 | 阶段 ≤2：`体重管理评估` → 首诊评估（新客态 `?state=new`，见 PLAN-01）或随访评估（按阶段分流）；阶段 ≥3 的吸底按钮 demo 为问 AI 助理，AI 一期不做，一期此位置的按钮形式待确认 |

- 文章卡显示：标题、导语、meta 行（`{审核医生}审核 · {审核日期}`，如 `李医生审核 · 11/03`）；无封面图。
- 下架文章即时消失，列表重排不留空位。
