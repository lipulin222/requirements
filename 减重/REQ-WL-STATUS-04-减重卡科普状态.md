# 减重卡 · 阶段① 购前科普

> 编号 `REQ-WL-STATUS-04` ｜ 项目：科学减重（WL）｜ 模块：服务状态与卡片 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[健康订阅区 Demo（阶段①）](https://lipulin222.github.io/health-subscription-demo/online-service.html?stage=1) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 这张卡什么时候出现

阶段 ① 是减重卡的**默认阶段**，以下任一情况都显示它：

1. 能看到减重卡的用户，还没做过首诊评估问卷；同时也没买过健康订阅、没看过减重门诊（否则不展示卡，见 `REQ-WL-STATUS-01`）。
2. 一个疗程已经结束（维持期置顶 1 个月后），后台没有新的状态更新——卡片回到本阶段。

## 2. 卡片上显示什么（自上而下）

卡头（图标 + `体重管理` + 猜你想问轮播）为所有阶段共用，统一规则见本单第 4 节。

1. **四个分类入口**，横排四等分，相邻之间浅灰竖线分隔。每个入口两行、居中：上行为深色主词，下行为灰色说明（小一号）：
   - `效果` — `多久有变化`
   - `安全` — `副作用说明`
   - `花费` — `价格说明`
   - `使用` — `操作方法`
2. **底部按钮组**：左 `询问护士`（浅色次按钮，跳 AI 减重助理对话页）+ 右 `快速评估`（青色实底 + 白字，大圆角）；按钮下方不放任何小字。

## 3. 猜你想问（本阶段）

本阶段轮播 5 条购前科普问题（Demo 里直接写在页面）：`GLP-1 到底是怎么起作用的` / `没明显副作用，是不是药没效果` / `减重期间能喝酒吗` / `漏服了一次怎么办` / `平台期怎么判断，要紧吗`。

## 4. 卡头与猜你想问（各阶段共用规则）

1. **卡头**：左侧方形圆角图标（浅青底 + 体重秤图形）；右侧第一行 `体重管理`（大号深色加粗），第二行为猜你想问轮播：`猜你想问` 青色标签 + `·` + 当前问题（深灰）+ 右侧箭头 `›`。
2. 卡头下方一条浅灰分隔线，横贯卡片。
3. 轮播每 2.6 秒换一条，循环播放；`猜你想问` 前缀固定不动，只换问题文字。
4. 正式上线时，各阶段的问题和对应文章链接一起从知识库取，运营增删文章后轮播跟着变；点卡头第二行跳到当前问题对应的文章。Demo 里问题直接写在页面中。

## 5. 点击与跳转

| 位置 | 点击后去哪 |
| --- | --- |
| 卡头第二行（`猜你想问 · 问题 ›`） | 科普文详情页（`edu-article/index.html?a=N`） |
| 四个分类入口 | 科普知识库首页的对应分组（`patient-education/index.html?stage=N#/g/{know/safe/life/run}`） |
| `快速评估` | 首诊问卷（`?state=new`，见 `REQ-WL-PLAN-01`） |

## 6. 验收
