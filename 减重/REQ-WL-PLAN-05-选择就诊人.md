# 选择就诊人

> 编号 `REQ-WL-PLAN-05` ｜ 项目：科学减重（WL）｜ 模块：方案·评估·随访 ｜ 优先级 P2 ｜ 状态：**暂缓**（入口已下线，待就诊人管理立项后重启）

---

## 1. 规则

- 首次进入首诊评估前，先选择就诊人。
- 页面不单独设计：直接用现网现成的半屏浮层组件承载（开发知道该组件），本单只定逻辑。
- 浮层内是就诊人列表，单选：点选一位，再点可取消；默认无人选中。
- 选中后在浮层内展示该就诊人详情：姓名 / 性别 / 年龄 / 身高 / 体重 / BMI / 腰围 / 过敏史，只读，由健康档案接口带入。

## 2. 出口

| 状态 | 吸底按钮 | 行为 |
| --- | --- | --- |
| 未选中 | `请选择就诊人` | 置灰，无法进入评估 |
| 已选中 | `确认，开始评估` | 所选就诊人带入首诊评估（PLAN-01） |

## 3. 验收

- [ ] 未选中无法进入评估；选中可取消重选
- [ ] 详情随选中切换，内容与健康档案一致
- [ ] 浮层复用现网现成的半屏浮层组件，不新开发 UI
