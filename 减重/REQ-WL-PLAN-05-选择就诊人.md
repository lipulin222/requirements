# 选择就诊人

> 编号 `REQ-WL-PLAN-05` ｜ 项目：科学减重（WL）｜ 模块：方案·评估·随访 ｜ 优先级 P0 ｜ 状态：**待评审**（一期范围）

---

## 1. 规则

- 首次进入首诊评估前，先选择就诊人。
- 页面不单独设计：直接用现网现成的半屏浮层组件承载（开发知道该组件），本单只定逻辑；不额外开发页面，主要工作是对这个组件的拉取和联调。
- 浮层内**只显示用户本人一个就诊人，不展示其他关系人**（家人、亲属等都不能选，一期只能给自己做评估）。
- 单选：点选自己后，在浮层内展示本人详情：姓名 / 性别 / 年龄 / 身高 / 体重 / BMI / 腰围 / 过敏史，只读，由健康档案接口带入。

## 2. 出口

| 状态 | 吸底按钮 | 行为 |
| --- | --- | --- |
| 未选中 | `请选择就诊人` | 置灰，无法进入评估 |
| 已选中 | `确认，开始评估` | 所选就诊人带入首诊评估（PLAN-01） |

## 3. 验收

- [ ] 未选中无法进入评估
- [ ] 浮层内只显示本人，不出现其他关系人；选中可取消重选
- [ ] 详情随选中切换，内容与健康档案一致
- [ ] 浮层复用现网现成的半屏浮层组件，不新开发 UI
