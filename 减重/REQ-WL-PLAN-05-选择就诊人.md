# 选择就诊人

> 编号 `REQ-WL-PLAN-05` ｜ 项目：科学减重（WL）｜ 模块：方案·评估·随访 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[选择就诊人](https://lipulin222.github.io/health-subscription-demo/weight-management/Patient-select/index.html)

---

## 1. 规则

- Demo 里首页 `快速评估` 直接进首诊问卷，不经过本页；本页目前没有上游入口，是一张独立页面。正式上线若要保留，需要补上入口。
- 页面与顶栏标题 `选择就诊人`。列出 3 位就诊人（李蔓 / 邢骥 / 邢博衍）和一个 `添加` 占位，卡头右侧 `查看全部`。
- 单选：点一位选中，再点一次取消。选中后展示本人详情：姓名、性别 · 年龄、身高、体重、BMI、腰围、过敏史，只读，来自健康档案。
- 吸底按钮：没选中时为 `请选择就诊人`（置灰，点了提示 `请先选择就诊人`）；选中后变 `确认，开始评估`，进首诊问卷。
- `添加`、`查看全部` 目前只提示 `示例 Demo：添加就诊人入口待接入` / `示例 Demo：全部就诊人列表待接入`；顶栏「更多」提示 `评估结果为初步建议，不构成诊断和处方`。
- 返回回线上服务首页。

## 2. 验收

- [ ] 没选中无法进入评估；选中可取消重选
- [ ] 详情随选中切换，字段与健康档案一致
- [ ] 选中后按钮变 `确认，开始评估`，进首诊问卷
- [ ] `添加`、`查看全部` 与「更多」提示原文一致
- [ ] 正式上线前补上进入本页的入口

## 3. 埋点

本单不上报，就诊人环节由后台记录（口径见 `REQ-WL-BASE-01` 第 3.3 节）。
