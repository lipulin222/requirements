# 健康订阅区结构与排序规则

> 编号 `REQ-WL-STATUS-02` ｜ 项目：科学减重（WL）｜ 模块：服务状态与卡片 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[健康订阅区 Demo](https://lipulin222.github.io/health-subscription-demo/) ｜ 埋点：`REQ-WL-BASE-01`

## 1. 首页整体结构（自上而下）

健康订阅区是「线上服务」首页的第一个内容区块；页面其余区块沿用设计稿，不在本单展开：

1. 顶部：渐变头部背景 + 左对齐大标题 `线上服务` + 搜索按钮 + 健康助手按钮 + 右上角胶囊。
2. **健康订阅区块**（本单范围，见下）。
3. 线上问诊（头像 + 名称 + 科室横滑行：儿科 / 皮肤科 / 耳鼻喉科 / 内全科 / 全部）。
4. 视频心理咨询、家庭私人医生（金刚位）。
5. 通栏 banner、底部 TabBar（预约门诊 / 线上服务 / 消息 / 健康工具 / 我的）、AI 助手浮钮。

## 2. 健康订阅区块（自上而下）

标题、专项标签、减重卡同属**一张连续的白色卡片**：

1. **标题行**：`健康订阅` 艺术字标题（设计稿黑色字体图形，居左）。
2. **专项标签行**：横向排列 `减重` `痤疮` `过敏` `血脂` `痛风`。
   - 当前选中 `减重`：青色底色高亮态。
   - 其他标签：灰底深灰文字。
   - 点其他专项标签跳各自原有页面（Demo 里因目标页缺失仅演示选中态切换，线上以本条为准）。
3. **减重卡**：只有减重有卡片，卡片占满整行，位于标签行下方；卡片内部各阶段见 `REQ-WL-STATUS-01`、`REQ-WL-STATUS-04` ~ `REQ-WL-STATUS-08`。

## 3. 两种用户状态

首页有两种用户状态，减重卡的起始阶段不同：

- **未开启减重的纯新用户**：从阶段 ① 购前科普开始。
- **已开启减重的新用户**：起始阶段由服务端按用户数据判定下发（Demo 中默认落在阶段 ④ 提醒 / 续费，仅为演示）。

## 4. 排序规则

1. 被灰度到减重卡的用户，减重卡固定在健康订阅区第一位。
2. 其他专项没有卡片，只有上面那排标签入口，点击直接跳各自原有页面。

## 5. 验收

- [ ] 健康订阅区块为一张连续白卡：艺术字标题 + 专项标签行 + 减重卡
- [ ] 五个专项标签顺序为 减重 / 痤疮 / 过敏 / 血脂 / 痛风；`减重` 为选中态
- [ ] 点其他专项标签跳各自原有页面
- [ ] 被灰度到减重卡的用户，减重卡排第一位
- [ ] 新客从阶段 ① 开始；老客起始阶段由服务端下发
- [ ] App 与小程序一致
