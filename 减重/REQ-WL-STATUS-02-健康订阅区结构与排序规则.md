# 健康订阅区结构与排序规则

> 编号 `REQ-WL-STATUS-02` ｜ 项目：科学减重（WL）｜ 模块：服务状态与卡片 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[线上服务页](https://lipulin222.github.io/online-health-care/weight-companion-ui/online-service.html) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 区域结构（自上而下，所有卡片共用）

1. **头图区**（浅青色底）：标题 `健康订阅`（深色加粗），右侧一个药瓶插图（药瓶 + 药片 + 胶囊，纯装饰，不可点）。
2. **专项标签行**：横向排列 `减重` `痤疮` `过敏` `血脂` `痛风`。
   - 当前选中 `减重`：白底 + 青色描边 + 青色文字。
   - 其他标签：白底、深灰文字、无描边。
3. **卡片区**：只有减重有卡片，卡片占满整行，位于标签行下方；卡片内部各状态见 `REQ-WL-STATUS-04` ~ `REQ-WL-STATUS-08`。

## 2. 排序规则

1. 被灰度到减重卡的用户，减重卡固定在健康订阅区第一位。
2. 其他专项没有卡片，只有上面那排标签入口，点击直接跳各自原有页面。

## 3. 验收

- [ ] 头图区标题为 `健康订阅`，右侧有药瓶插图，插图不可点
- [ ] 五个专项标签顺序为 减重 / 痤疮 / 过敏 / 血脂 / 痛风
- [ ] `减重` 为选中态（白底 + 青色描边 + 青色文字），其余标签白底深灰文字无描边
- [ ] 点其他专项标签跳各自原有页面
- [ ] 被灰度到减重卡的用户，减重卡排第一位
