## 1. 规则

### 1.1 层级与返回

入口页（Portal 减重卡 `查看更多` 进入）→ 汇总页（三个列表页三选一）→ 明细页。汇总页返回回入口页，入口页返回回 Portal。

### 1.2 入口页

三个入口自上而下：

| 入口 | 角标 |
| --- | --- |
| 历次评估结论建议汇总 | N 份 |
| 每月减重小结及后续建议 | N 期 |
| 套餐订单记录 | N 条 |

角标数量与列表条数一致。

「每月减重小结及后续建议」一栏在有待办时右上角显示红色角标（详见 RECORD-01 的红点联动规则）：

- 待办为「生成月报」时：角标文字「生成月报」，点击这一栏直接进入快问快答页面。
- 待办为「新月报」时：角标文字「new」，点击这一栏直接进入最新一期月报内容。
- 红点状态与首页减重卡「查看更多」按钮上的红点保持一致；进入月报内容后两处红点同时消失。

### 1.3 历次评估结论建议汇总（列表页）

- 单列统一卡片：日期 + 标题 + 一句摘要，无数据块、无标签，点击进对应报告。
- 本页底部没有吸底按钮。

### 1.4 每月减重小结及后续建议（列表页）

与 1.3 同款结构，点击进月报详情（RECORD-01）。

### 1.5 套餐订单记录（列表页）

- **整页用现成的订单记录列表页（即「我的订单」页），不需要新做**。本单只约定：入口页点「套餐订单记录」直接进该现成页面。
- 页内的订单卡样式、金额、操作按钮（`查看物流` → 订单详情页，也是现成页面）、空态等，全部沿用现成页面已有逻辑，本单不做约束、不重复定义。

## 2. 验收

- [ ] 三个入口名称与角标与单内一致，角标数量与列表条数一致
- [ ] 月报栏红点与首页卡片联动：待办「生成月报」显示「生成月报」并直达快问快答；未读显示「new」并直达最新月报；进入月报内容后红点消失
- [ ] 评估 / 月报两个列表页统一样式，无数据块无标签
- [ ] 两个列表页底部都没有吸底按钮
- [ ] 「套餐订单记录」进的是现成订单记录列表页，无需开发
- [ ] 空列表有空态（评估 / 月报两个列表页）
