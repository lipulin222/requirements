1. 规则

1.1 层级与返回

入口页（Portal 减重卡 查看更多 进入）→ 汇总页（三个列表页三选一）→ 明细页。汇总页返回回入口页，入口页返回回 Portal。

1.2 入口页

三个入口自上而下，每个入口为「名称 + 描述」两行文字，右侧角标数量：

入口名称 描述 角标
评估报告 历次评估结论建议汇总 N 份
减重月报 每月减重小结及后续建议 N 期
相关订单 套餐订单记录 N 条

角标数量与列表条数一致。

「每月减重小结及后续建议」一栏在有待办时右上角显示红色角标（详见 RECORD-01 的红点联动规则）：

  • 待办为「生成月报」时：角标文字「生成月报」，点击这一栏进入月报的列表页，再点列表下方 生成最新月报 进入快问快答。
  • 待办为「新月报」时：角标文字「new」，点击这一栏直接进入最新一期月报内容。
  • 红点状态与首页减重卡「查看更多」按钮上的红点保持一致；进入月报内容后两处红点同时消失。

1.3 历次评估结论建议汇总（列表页）

  • 页面标题 评估报告；单列统一卡片：日期 + 标题 + 一句摘要 + 右下 查看详情 ›，无数据块、无标签，点击进对应报告。
  • 列表按报告生成时间倒序展示（最新在最上）。
  • 空状态：还没有任何评估报告时，列表区居中显示一行灰字 暂无内容。
  • 每份报告一个独立链接；同一个月可生成多份，各自独立成条，不在同一条上迭代更新（时效规则见 REQ-WL-PLAN-02 第 1.4 节）。
  • 吸底常驻 新增评估 → 随访问卷（PLAN-04）；仅本列表显示。

1.4 每月减重小结及后续建议（列表页）

  • 页面标题 减重月报；与 1.3 同款卡片结构（每期标题形如 第 N 个月月报），点击进月报详情（RECORD-01）。
  • 本页底部没有吸底按钮。

1.5 套餐订单记录（列表页）

  • 在现成的订单页（Order-Records「已购套餐」）基础上改成 demo 的样子，不是新做页面：入口页点「相关订单」进入，页面交互与内容按 demo。
  • 订单卡结构（按 demo）：卡头 订单编号：O… + 状态（已完成 青色 / 配送中 橙色 / 已取消 灰色）；商品行 = 封面图 + 商品名 + 单价 + 规格 + × 1；底部右对齐 共 1 件，合计:¥X.00（金额橙色加粗）+ 操作按钮 查看物流（进订单详情，见 RX-03）/ 再次续订（进 RX-02）/ 评价（一期占位）。
  • 列表为空显示空态。

2. 验收

  • 三个入口名称、描述与角标与单内一致，角标数量与列表条数一致
  • 月报栏红点与首页卡片联动：待办「生成月报」显示「生成月报」，点击进月报列表页；未读显示「new」，点击直达最新月报；进入月报内容后红点消失
  • 评估报告列表页吸底 新增评估 进随访问卷；月报列表页无吸底按钮
  • 评估报告列表按生成时间倒序；同月多份报告各自独立成条、独立链接
  • 评估 / 月报两个列表页统一样式，无数据块无标签
  • 订单列表在现成订单页基础上改造，卡片结构、状态色与按钮按 demo
  • 空列表有空态：报告 / 月报列表空显示 暂无内容；订单列表用现成页的空态（插画 + 暂无记录）
