# 收银台与支付结果

> 编号 `REQ-WL-RX-02` ｜ 项目：科学减重（WL）｜ 模块：处方·健康订阅·订单 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[支付页](https://lipulin222.github.io/online-health-care/weight-companion-ui/Payment-Page/index.html) ｜ [支付成功页](https://lipulin222.github.io/online-health-care/weight-companion-ui/Payment-Success/index.html) ｜ 埋点：`REQ-WL-BASE-01`

## 1. 支付页

- 商品名、价格等信息由页面从后台接口拉取后展示，前台不写死；展示内容与用户在套餐页所选的套餐保持一致。
- 按钮 `提交支付`。
- 用户点击提交后，生成一笔待支付订单，同时开始计算 15 分钟的支付时限（从点击提交那一刻算起）。
- 提交 → 拉起支付（通道由技术方案定；demo 直接跳成功页）。
- 支付失败 / 取消：留本页可重试，toast `支付未完成，请重试`。

## 2. 待支付订单的处理

- 用户已下单但还没支付时，这笔订单不会消失，会挂在订单列表页里，状态显示为「待支付」。
- 从下单起 15 分钟内，用户可以随时在订单列表页看到这笔订单，点进去回到收银台继续支付。
- 超过 15 分钟还没有支付，订单自动关闭，订单列表页里这笔订单的状态更新为「已关闭」，不能再支付；用户需要重新下单。
- 已关闭的订单不会自动消失，一直留在订单列表页里可以查看；用户也可以把它删掉，删掉后订单列表页里就不再显示。

## 3. 支付成功页

- 结构：成功标识 + `支付成功` + 倒计时提示块 + 订单入口文字链。
- 倒计时：`5 秒后自动跳转完善收货信息页面。` 逐秒递减 → `正在进入完善收货信息页面…` → 跳 RX-03。
- 兜底文字链 `没有自动跳转？点此完善收货信息 ›`（同目标）。
- 订单入口：`订单可在 我的-已购套餐及代金券 内查看` → Order-Records。
- 顶栏返回：清倒计时，无历史回支付页。

## 4. 关键值

| 项 | 值 |
| --- | --- |
| 商品名 / 价格 | 以后台接口返回为准，前台不写死 |
| 待支付时限 | 从下单起 15 分钟，超时自动关闭订单 |
| 倒计时 | 5 秒 |
| 成功去向 | RX-03 |
| 订单状态初值 | 已支付 |

## 5. 验收

- [ ] 进入收银台时，商品名与价格来自后台接口，与套餐页所选套餐一致；换套餐后收银台同步变化
- [ ] 下单未支付时，订单列表页能立刻看到「待支付」订单，点进去可回到收银台继续支付
- [ ] 下单后超过 15 分钟仍未支付，订单自动变为「已关闭」，不能再支付
- [ ] 已关闭订单可在订单列表页查看，也可删除，删除后列表里不再显示
- [ ] 成功后 5 秒必达 RX-03；手动点文字链同目标
- [ ] 倒计时期间离开不二次跳转
- [ ] 支付成功状态以服务端回调为准，回调成功后才启动倒计时
