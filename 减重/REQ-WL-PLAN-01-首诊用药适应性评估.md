# 首诊用药适应性评估

> 编号 `REQ-WL-PLAN-01` ｜ 项目：科学减重（WL）｜ 模块：方案·评估·随访 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[评估问卷](https://lipulin222.github.io/online-health-care/weight-companion-ui/weight-management/Medication-eligibility-assessment/index.html) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 规则

### 1.1 路径

- 入口：Portal 减重卡〔快速评估〕；新老客共用本页，进入时按用户状态自动分流（新客 `?state=new`，老客为缺省或 `?state=old`）。
- 出口：提交确认 → 中转页 → 评估报告（PLAN-02）。
- 只做用药适应性判断，不下诊断。
- 页面 UI 直接用现有的问卷组件实现，不做额外 UI 开发。

### 1.2 新老客分流

- **老客（缺省 / state=old）——先确认档案，只补填缺的**：
  1. 进入先看到「确认你的信息」页，副文案 `以下来自你在卓正登记的历史信息。`——页面从健康档案拉取已有信息供用户确认，字段：姓名 / 定居城市 / 年龄 / 性别 / 身高 / 体重 / BMI（自动计算，不可改）/ 基础病。
  2. 除 BMI 外每一行都可以点开修改，改完即存。
  3. 点确认开始答题后，档案已覆盖的题目**不再重复问**——性别、年龄、身高体重、确诊疾病（基础病带入；没有基础病按「以上都没有」处理）四题直接跳过，从后续题继续作答。
- **新客（state=new）——全部重新填**：从第 1 题开始把整份问卷答完，不预填任何信息。
- 汇总页里，由档案带入的答案旁标注「档案」，与用户现场填写的区分开。

### 1.3 题目（10 题，一屏一题，顺序固定）

题目内容取自医疗团队文档《首诊问卷demo》（@望时 提供）：

| # | 问的内容 | 患者看到的问法与选项 |
| --- | --- | --- |
| 1 | 性别 | 男 / 女 |
| 2 | 年龄 | 周岁（数字填写） |
| 3 | 身高、体重 | 身高 `____` cm、体重 `____` kg；BMI 自动计算，不可改 |
| 4 | 体重变化原因 | 您认为导致您体重增加的主要原因有哪些？（多选）饮食习惯（如爱吃甜食、夜宵、外卖多）/ 缺乏运动、久坐 / 工作压力大、情绪性进食 / 睡眠不足 / 生病或手术后 / 服用某些药物，如激素类、情绪类药物（精神科药物）/ 怀孕、产后、更年期 / 遗传、家族因素 / 其他 `____` |
| 5 | 已确诊的疾病 | 您目前是否确诊过以下疾病？（可多选）高血压 / 糖尿病、血糖偏高 / 高血脂 / 脂肪肝 / 痛风、高尿酸血症 / 冠心病、心脏病、中风 / 睡眠呼吸暂停综合征（睡觉憋气）/ 关节炎、膝盖疼 / 多囊卵巢综合征、月经不调、妊娠期糖尿病（仅女性显示）/ 胃食管反流（烧心）/ 抑郁症、焦虑症 / 以上都没有 |
| 6 | 指标偏高 | 最近的体检是否提示以下指标偏高，但医生还没有确诊？（可多选）血压偏高 / 血糖偏高 / 血脂偏高 / 尿酸偏高 / 体检提示脂肪肝 / 以上都没有 |
| 7 | 禁忌症 | 是否有甲状腺髓样癌或 2 型多发性内分泌腺瘤病（本人或直系亲属）？有 / 没有 / 不确定 |
| 8 | 其他现在或曾经有过的病 | 胰腺炎 / 胆结石或胆囊炎 / 严重胃肠疾病 / 糖尿病视网膜病变 / 严重肾脏疾病 / 进食障碍 / 以上都没有 |
| 9 | 是否在备孕、怀孕或哺乳 | 是 / 否 / 不确定 |
| 10 | 除体重数字外的治疗目标 | 改善指标 / 减轻关节疼痛 / 改善睡眠精力 / 穿进特定衣服 / 能够停药 / 其他 |

- 分流逻辑：不同选择如何影响报告分支与结论，待 @望时 确认（分支判定见 `REQ-WL-PLAN-02`）。

### 1.4 答题交互

- 单选点中 180ms 自动跳下一题；多选每次点击重置 800ms 计时，停顿后自动跳。
- 选项题未答时「下一题」置灰，点击 toast `先选一项，再继续`；数字题与开放题不强制。
- 答题过程中可以返回到已答过的题修改答案，改完再继续往下答。
- 汇总页单题修改：主按钮 `保存并返回`，答完回汇总，不显示进度条。

### 1.5 安全题（不中断）

- 第 7 题（禁忌症）、第 8 题（其他病史）、第 9 题（备孕 / 怀孕 / 哺乳）是安全筛查题。
- 在这三题里选到有风险的选项时，**问卷不中断**，用户继续把剩下的题答完，正常进汇总页、中转页；用药不合适的结论由评估报告页给出（不适应分支的规则见 `REQ-WL-PLAN-02`）。
- 哪些选项算高风险、如何影响报告结论，待 @望时 确认。

### 1.6 汇总与中转

- 提交前出汇总页 `确认你提交的内容`：逐题答案 + BMI 行（标 `自动计算`，不可改），未填显示 `未填写`，每行 `修改`。
- 确认提交 → 中转页三步：`已收到你的问卷` → `正在核对用药安全` → `正在生成你的评估报告`，步进 800ms，末步停 600ms 进报告页。
- 页面固定声明：`本页内容基于你填写的问卷与已关联的健康数据生成，为初步评估建议，不构成诊断和处方。`

- [ ] 老客确认档案后，性别 / 年龄 / 身高体重 / 确诊疾病四题不再出现，直接从后续题继续
- [ ] 新客从第 1 题全部重填，无任何预填
- [ ] 汇总页中档案带入的答案标「档案」

- [ ] 汇总页每行可修改回跳；BMI 行不可改
