# 首诊用药适应性评估

> 编号 `REQ-WL-PLAN-01` ｜ 项目：科学减重（WL）｜ 模块：方案·评估·随访 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[评估问卷](https://lipulin222.github.io/health-subscription-demo/weight-management/Medication-eligibility-assessment/index.html) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 规则

### 1.1 入口与出口

- 首页减重卡 `快速评估` 固定带 `?state=new`，进本页后全部重填。
- 直接打开本页（不带参数，或带 `?state=old`）是老客：先确认健康档案，再补答剩下的题。
- 评估报告 `推荐给亲友做评估` 分享出来的链接带亲友标记，亲友不用登录即可答题。
- 提交后进中转页，再到评估报告。本页只做用药适应性判断，不下诊断。页面直接用现有问卷组件，不做额外 UI 开发。

### 1.2 老客先确认档案

1. 进入先看到 `确认你的信息`，副文案 `以下来自你在卓正登记的历史信息。`；字段：姓名、定居城市、年龄、性别、身高、体重、BMI（自动算，不可改）、基础病。
2. 除 BMI 外每行都可以点开修改，改完即存。
3. 确认后，档案已覆盖的四题不再问：性别、年龄、身高体重、确诊疾病，从 `最近的体检是否提示以下指标偏高` 接着答。
4. 汇总页里档案带入的答案标 `档案`，和用户现场填的区分开。

### 1.3 题目（10 题 + 1 道选填开放题，一屏一题，顺序固定）

| # | 题目 | 选项 / 填法 |
| --- | --- | --- |
| 1 | 你的性别 | 女 / 男 |
| 2 | 你的年龄 | 填数字（岁），必须填有效数字才能继续 |
| 3 | 你的身高与体重 | 身高 cm、体重 kg，BMI 自动算；可留空 |
| 4 | 你认为导致你体重增加的主要原因有哪些（多选） | 饮食习惯（如爱吃甜食、夜宵、外卖多）/ 缺乏运动 / 久坐 / 工作压力大 / 情绪性进食 / 睡眠不足 / 生病或手术后 / 服用某些药物（如激素类、情绪类药物）/ 怀孕 / 产后 / 更年期 / 遗传 / 家族因素 / 其他（选后填补充说明） |
| 5 | 你目前是否确诊过以下疾病（多选） | 高血压 / 糖尿病 / 血糖偏高 / 高血脂 / 脂肪肝 / 痛风 / 高尿酸血症 / 冠心病 / 心脏病 / 中风 / 睡眠呼吸暂停综合征（睡觉憋气）/ 关节炎 / 膝盖疼 / 胃食管反流（烧心）/ 抑郁症 / 焦虑症 / 以上都没有 |
| 6 | 最近的体检是否提示以下指标偏高（多选） | 血压偏高 / 血糖偏高 / 血脂偏高 / 尿酸偏高 / 体检提示脂肪肝 / 以上都没有 |
| 7 | 你或你的直系亲属，是否被诊断过甲状腺髓样癌或 2 型多发性内分泌腺瘤病 | 有 / 没有 / 不确定 |
| 8 | 你现在或曾经有过以下情况吗（多选） | 胰腺炎 / 胆结石或胆囊炎 / 严重胃肠疾病（如胃轻瘫、炎症性肠病、长期严重呕吐或腹泻）/ 糖尿病视网膜病变 / 严重肾脏疾病 / 进食障碍（暴食、催吐、过度节食）/ 以上都没有 |
| 9 | 你是否在备孕、怀孕或哺乳 | 是 / 否 / 不确定；只问女性，男性跳过并记「否」 |
| 10 | 除体重数字外，你的治疗目标（多选） | 改善健康指标（血糖 / 血脂 / 血压等）/ 减轻关节疼痛 / 改善睡眠精力 / 追求好身材，穿衣服好看 / 其他 |
| 11 | 你还有什么想补充的 | 选填开放框，可留空 |

- 第 5、6、8 题里 `以上都没有` 与其他选项互斥；选 `其他` 后出现 `请补充说明` 输入框。
- 第 7、8、9 题是安全筛查题。选到有风险的选项不中断问卷，用户照样答完、进汇总和中转；不适合的结论由评估报告给。
- 答案对应的报告结论：安全题命中或 BMI 低于 24 → 无需减重；确诊慢病 → 需要减重与慢病结合管理；只有指标偏高 → 需要减重管理；其余 → 需要减重管理。

### 1.4 答题与汇总

- 单选点中即跳下一题，多选停顿后自动跳；选项题没选时 `下一题` 置灰并提示 `先选一项，再继续`。数字题（身高体重）和开放题不强制。
- 可以返回已答过的题修改，改完继续往下答。
- 提交前出汇总页 `确认你提交的内容`：逐题答案 + BMI 行（标 `自动计算`，不可改），没填显示 `未填写`，每行有 `修改`；单题修改后点 `保存并返回` 回汇总。
- 页脚声明：`本页内容基于你填写的问卷生成，为初步评估建议，不构成诊断和处方。`

### 1.5 中转页与亲友链路

- 确认提交后显示 `已收到你的问卷` → `正在核对用药安全` → `正在生成你的评估报告`，三步各停 800ms，末步再停 600ms 进报告页；页面上没有可点的操作。
- 亲友链路（带亲友标记）第二步改为 `正在创建临时健康档案`，其余两步不变；提交时先建临时档案，把答案挂进去再生成报告，进报告页时继续带亲友标记。

## 2. 验收

- [ ] 首页 `快速评估` 进新客态，全部重填、无预填
- [ ] 老客进入先见 `确认你的信息`，字段来自健康档案；除 BMI 外可改
- [ ] 老客跳过性别、年龄、身高体重、确诊疾病四题；汇总页档案答案标 `档案`
- [ ] 11 道题的题干、选项与单内一致；`以上都没有` 互斥、`其他` 可补充说明
- [ ] 男性跳过第 9 题；安全题选到风险项不中断问卷
- [ ] 汇总页每行可改、BMI 不可改；中转页无操作入口，必达报告页
- [ ] 亲友提交后建临时档案，中转页第二步为 `正在创建临时健康档案`，报告页带亲友标记
