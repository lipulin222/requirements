# 减重评估报告：分支判定与结论

> 编号 `REQ-WL-PLAN-02` ｜ 项目：科学减重（WL）｜ 模块：方案·评估·随访 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[评估报告](https://lipulin222.github.io/health-subscription-demo/weight-management/Assessment-report/index.html)（顶栏「⋯」可切换 14 位样例患者） ｜ 埋点：`REQ-WL-BASE-01`

## 1. 规则

### 1.1 分支判定

| 分支 | 条件 |
| --- | --- |
| adapt 不适应 | BMI < 24 且无病种/指标异常且无反弹史 |
| chronic 慢病 | 确诊糖尿病/高血压等慢病，或反弹 3 次及以上 |
| mild 轻微异常 | 指标偏高（未确诊）/ 脂肪肝，或反弹 1–2 次 |
| normal 无慢病 | 其余 |

- 分支怎么划分、各题选项分别分流到哪个分支，待 @望时 确认。

### 1.2 结论头

- 档案行：姓名 · 性别 · 年龄 · 身高 · 体重 · BMI。
- 三档刻度 `减重建议`：`无需减重 → 需要减重管理 → 立即减重`；adapt=第 1 档，mild/normal=第 2 档，chronic=第 3 档。
- 一句话总结：「当前情况 → 建议」句式，病名取问卷勾选原文；chronic 加「线下优先」建议行。
- GLP-1 匹配度：adapt=`不适用` 10% / chronic=`需医生面诊评估` 65% / mild·normal=`较高` 78%（待医疗定稿）。

### 1.3 吸底分流

| 分支 | 吸底按钮 | 去向 |
| --- | --- | --- |
| chronic / mild | `线上咨询`、`预约面诊`（并列两个按钮） | 线上咨询弹线上咨询二维码；预约面诊进预约就诊页（现成页面，无需开发） |
| normal | `邀请亲友评估`（左）、`了解用药详情`（右），并列两个按钮 | `邀请亲友评估`：分享 / 复制评估入口链接给亲友（行为同 adapt 分支的「推荐给亲友做评估」）；`了解用药详情`：首诊套餐页（RX-01），过时效拦截规则不变 |
| adapt | `推荐给亲友做评估` | 点击后把评估入口分享出去，规则见 1.5 |

页脚固定声明：`本页内容基于你填写的问卷与已关联的健康数据生成，为初步评估建议，不构成诊断和处方。`

### 1.4 报告时效与购药拦截

- 每次评估生成一份独立报告，各有单独的链接；同一个月可以生成多份，不在同一份报告上迭代更新。
- 报告时效：满足任一条件即视为已过时效——① 这份报告已完成订单转化（已由它产生支付/订单）；② 报告生成时间超过 30 天。
- 已过时效的报告仍可查看，但**点击购药时阻拦进入支付，并 toast 提示：`评估报告已过时效，请重新评估。`**；toast 后引导用户跳转重新评估，去向为随访问卷（`REQ-WL-PLAN-04`）。
- 用户重新完成评估生成新报告后，可正常购药。

### 1.5 亲友评估（分享链路）

走通「老用户把评估推荐给亲友 → 亲友免登录做完评估拿到报告 → 想留下成果再引导登录」的完整链路，分三段：

**① 报告页发起分享（本页，无需减重分支）**

- 吸底按钮 `推荐给亲友做评估`：点击后调起系统分享，把评估问卷入口链接分享出去；设备不支持系统分享时，自动复制链接并 toast `评估链接已复制，发给亲友即可开始评估`。
- 分享出去的链接自带「亲友」标记（URL 参数），亲友打开后直达评估问卷（PLAN-01），不需要登录。

**② 亲友免登录做完评估**

- 亲友从分享链接进入问卷，答题流程与普通用户完全一致。
- 问卷提交时，系统先为这位亲友建立一个临时档案（临时 UIN），再把评估报告挂在这个临时档案下生成；报告页继续带着亲友标记。

**③ 亲友在报告页的登录引导（带亲友标记时）**

- 进入报告页时 toast 提示一次：`亲友评估模式：已使用临时档案，登录后可长期保存`。
- 点返回 / 退出时，弹出居中对话框，不直接退出：
  - 标题 `建议先登录保存`；说明 `登录后，本次评估与报告会保存到你的账户；不登录的话，退出后内容将永久丢失。`
  - 按钮 `登录保存`：走登录流程（登录方式待技术确认），登录成功后临时档案并入用户账户；
  - 按钮 `仍要退出`：正常退出返回。
- 点 `了解用药详情`（原查看用药方案）时不出报告、不进套餐页，toast 提示 `请先登录后再查看用药方案`（toast 文案是否随按钮改名同步调整，待产品确认）。

## 2. 验收

- [ ] 四分支与 1.1 条件一一对应，同一问卷结果重复进入结果稳定
- [ ] 报告已转化订单、或生成超 30 天时，点击购药被阻拦并 toast「评估报告已过时效，请重新评估。」，随后引导进随访问卷（PLAN-04）；未过时效可正常进入支付
- [ ] 同一个月生成多份报告时，每份报告链接独立，互不覆盖
- [ ] 吸底按分支正确分流，无 404
- [ ] 刻度、总结、匹配度按分支正确渲染
- [ ] 无需减重分支吸底按钮为「推荐给亲友做评估」，点击可分享 / 复制评估入口链接，toast 原文一致
- [ ] 亲友从分享链接打开问卷无需登录，提交后系统建立临时档案并生成报告，报告页带亲友标记
- [ ] 亲友态报告页：进入有一次「已使用临时档案」toast；点退出弹「建议先登录保存」对话框，「仍要退出」正常退出、「登录保存」走登录流程
- [ ] normal 分支吸底为两个按钮：左 `邀请亲友评估`（分享 / 复制评估入口链接）、右 `了解用药详情`（进首诊套餐页）
- [ ] 亲友态点「了解用药详情」被拦截，toast「请先登录后再查看用药方案」，不进入套餐页
