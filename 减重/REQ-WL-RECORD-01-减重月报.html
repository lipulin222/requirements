减重月报

需求单 · 科学减重（WL） · 交付目标：可上线面向用户使用（H5 + 微信小程序）

编号 REQ-WL-RECORD-01 ｜ 项目：科学减重（WL）｜ 模块：记录沉淀 ｜ 优先级 P0 ｜ 状态：待评审 Demo：减重月报 ｜ 埋点：REQ-WL-BASE-01

1. 规则

1.1 入口与返回

用户可以通过两个途径进入月报：

  • 从线上服务首页进：减重卡片右下角「查看更多」按钮带红点提醒时，点「查看更多」进入聚合页，再点「每月减重小结及后续建议」一栏进入月报。
  • 从历史列表进：在「查看更多」聚合页点「每月减重小结及后续建议」，进入列表页后再选某一期月报查看。

红点提醒与页面联动（分两种情况，红点同时出现在首页减重卡和聚合页两处，状态保持一致）：

  • 情况一「生成月报」：上一个月已经过完，用户还没做这期的快问快答。
    1. 首页减重卡片的「查看更多」按钮右上角出现红色角标「生成月报」。
    2. 点「查看更多」进入聚合页后，「每月减重小结及后续建议」一栏右上角也出现红色角标「生成月报」。
    3. 点这一栏进入月报的列表页，列表下方有 生成最新月报 按钮，点击进入快问快答，答完（或跳过）后生成月报。
  • 情况二「新月报」：已经有生成好的月报，用户还没有看过。
    1. 首页减重卡片的「查看更多」按钮右上角出现红色角标「新月报」。
    2. 聚合页里「每月减重小结及后续建议」一栏右上角出现红色角标「new」。
    3. 点这一栏直接进入最新一期的月报内容。
  • 红点消除：用户进入月报内容后，首页卡片和聚合页两处的红点一起消失。
  • 重要约束：红点只出现在「查看更多」按钮和聚合页对应栏目的角标上，不改变减重卡片本身的按钮布局和展示逻辑；三个页面的红点状态由服务端统一判定和下发，保证联动一致（演示环境暂存本机模拟）。

返回规则（两个入口一样）：

  • 在月报流程的任何一步（包括正在回答快问快答）点返回，都是退出月报流程：回到进入月报之前的那个页面（聚合页或线上服务首页），不会停在月报页面上。
  • 快问快答答到一半就返回的，同样直接退出，不会跳过快问快答看到本期月报——月报要等答完或跳过后才生成放出。
  • 如果手机上没有上一页可退（例如从消息通知直接打开月报），返回回到线上服务首页的「进行中」状态。

1.2 页面结构（五种视图）

页面标题 减重月报 · 体重管理。从入口进来，默认先落在「减重月报列表页」；页内共五种视图：

视图 顶栏标题 说明
减重月报列表页（默认落地页） 减重月报 已生成月报的倒序列表 + 生成入口
快问快答 {X}月状态 单页速填 8 题，填完生成月报
月报详情 减重月报 某一期的完整内容
未到期次占位 减重月报 还没到期的期次，显示预计生成时间
空状态 减重月报 还没有第一期月报时

深链参数（供首页红点、聚合页、消息通知等场景直达）：?m=N 直接看第 N 期；?report=1 跳过快问快答直达最新一期；?data=none 空状态（演示无数据态）。

1.3 列表页（默认落地页）

  • 倒序只列出已生成的月报：每行两行文字——第一行 第 N 期 · 统计区间（灰），第二行该期标题（深色加粗），点击看该期详情。
  • 列表下方吸底一个通栏按钮 生成最新月报，点击进入快问快答。
  • 进入某个视图后，列表页的吸底按钮隐藏。

1.4 快问快答（单页速填）

  • 页内大标题 {X}月状态快问快答。填写口径：按填写时间定所属月份——当月 15 日（含）前填算上个月，15 日之后填算本月（例：11 月 14 日填 → 「10月状态」；11 月 16 日填 → 「11月状态」）。
  • 8 题一次列完（不是一屏一题），按三个分组排列：
    • 身体数据：现在体重多少？（数字，kg）/ 腰围多少？（数字，cm）/ 这一期的身体反应？（单选：没有明显反应 / 轻微恶心或饱胀 / 食欲明显下降 / 其他不适）
    • 生活习惯：平均每周运动几次？（单选：几乎不动 / 1–2 次 / 3–4 次 / 5 次以上）/ 平均每天睡多久？（单选：不足 6 小时 / 6–7 小时 / 7–8 小时 / 8 小时以上）/ 这一期的喝过酒吗？（单选：没喝 / 1–2 次 / 3 次以上）
    • 心理状态：这个月的状态？（单选：状态很好 / 还算顺利 / 有点吃力 / 快坚持不住）/ 最影响坚持的是？（多选：时间不够 / 应酬聚餐 / 食欲难控制 / 看不到变化 / 药物反应 / 情绪压力）
  • 全部选填：单选点选互斥、多选可叠加；不填任何一题也能直接点底部通栏按钮 生成月报 生成月报（空记录同样标记为本期已填）。
  • 提交后提示 已记录，随即进入本期月报。
  • 答案按期留存，供本期月报与医生端使用；不做医疗判定。

1.5 月报详情

月报内容来源待确认：每期月报的数据（体重记录、统计区间）和正文内容（分析文字、下月建议条目）从哪里来——是服务端生成后下发、还是客户端按记录数据拼装——需要和开发确认后才能定；本单只约定页面展示结构，不锁定内容来源方式。

顶部通栏配图：每期月报顶部有一张通栏大图，透顶展示（顶栏浮在图上，向下滚动约一屏图高后顶栏变实底）。

  • 按月份切换：配图与该期的起始月份对应（如 6 月开始的期次用 6 月的图），一年 12 个月各一张；跨月的期次按起始月份取图。翻看不同期次的历史月报时，配图随之变化。
  • 男版 / 女版两套素材为待交付项，demo 当前为按月份的单套素材；两套到位后按用户档案性别取版。

配图下方自上而下：

  1. 期头：小字眉标 体重管理 · 第 N 期月报 + 当期标题（如 第一个月：把节奏建立起来，每期一句，由内容侧产出）+ 一行元信息 统计区间 | 第 X–Y 周 · 28 天。
  2. 本期概览卡：体重变化折线图（5 个描点，首尾标数字）+ 四格指标 本月变化 / 累计变化 / BMI / 腰围 + 卡片底部文字按钮 查看历史月报（点击展开期数切换条，再点收起）。
  3. 期数切换条（默认收起）：列出全部期次的 第 N 期 胶囊，当前期高亮；未生成的期次为置灰样式并带 未生成 字样，点开是占位页（见 1.6）。
  4. 01 减重数据分析：图表下方一段文字，按当月、次月分成两段展示。当月讲这一期体重变化、走势和本期原因，次月讲下一月要做的事、要留意的事，以及什么留给医生判断；两段共 150–300 字。写法见 REQ-WL-DATA-02 减重月报提示词，不在这两段里写饮食、运动的具体做法。
  5. 02 下个月的饮食与运动：两个小标题 饮食 / 运动，各 3 条完整可执行动作。每条写清场景、一个当场能做的动作、在家能照着做的分量或次数，以及做不动时怎么换；动作要承接数据分析里指出的本期原因。不写个体化的千卡、蛋白克数、减重速度等数字，这些由医生确认后给出；不写「还差 2 次」这类考核式说法。
  6. 页脚：两行小字——测量口径 体重为晨起空腹测量，腰围为肚脐水平呼气末测量，体成分来自 InBody。本页为健康管理服务记录，不构成诊疗建议。；下方一个文字链 补填{X}月状态，点击重新打开快问快答（{X} 同样按 1.4 的填写口径计算）。
  7. 顶栏「更多」：toast 月报暂不支持导出。

1.6 未到期次占位

  • 配图 + 眉标 体重管理 · 第 N 期月报 + 大标题 这一期还没到总结的时候 + 元信息（区间 | 周数）。
  • 概览卡位置显示：预计生成时间 + 具体日期（每期结束后次日生成），说明 月报在每期结束后次日生成，包含这一期的减重数据分析，以及下个月的饮食与运动建议。 + 查看历史月报 按钮。

1.7 空状态

  • 还没有第一期月报时显示：空状态插画 + 一行标题 还没有减重月报。
  • 空状态下 生成最新月报 吸底按钮常驻，用户随时可以开始第一次快问快答填写。

2. 验收

  • 进入默认落在列表页：只显示已生成期次（倒序），生成最新月报 吸底按钮进快问快答
  • 快问快答 8 题单页列完，分组与选项文案与单内一致；全跳过点 生成月报 也能生成
  • 快问快答标题按填写口径显示 {X}月状态：15 日前填算上月、15 日后算本月
  • 月报详情：眉标、当期标题、元信息、概览四格、两模块内容与页脚声明齐全；补填{X}月状态 可重开快问快答
  • 查看历史月报 展开期数 chips，当前期高亮；点未生成期次进入占位页（这一期还没到总结的时候 + 预计生成时间）
  • 上月过完未做快问快答：首页「查看更多」红点「生成月报」，聚合页月报栏红点「生成月报」，点击进月报列表页，再经 生成最新月报 进快问快答
  • 有已生成未读月报：首页红点「新月报」，聚合页红点「new」，点击直达最新月报
  • 进入月报内容后，首页与聚合页红点同时消失；红点不改变减重卡片按钮本身的布局
  • 快问快答与月报页返回均回首页，不出现「返回看到月报」
  • 配图按该期起始月份切换；同一期月报男 / 女用户看到男版 / 女版素材；滚动过图后顶栏变实底
  • 顶栏「更多」提示 月报暂不支持导出
  • 无数据用户看到空状态（插画 + 还没有减重月报），且吸底 生成最新月报 常驻可点
  • 月报正文按 REQ-WL-DATA-02 减重月报提示词生成；数据分析按当月、次月分两段展示，饮食、运动各 3 条；逐句检查在该单验收
