# 科普文详情页

> 编号 `REQ-WL-EDU-02` ｜ 项目：科学减重（WL）｜ 模块：科普·内容 ｜ 优先级 P1 ｜ 状态：待评审
> Demo：[科普文详情页 v2](https://lipulin222.github.io/health-subscription-demo/edu-article-v2/index.html?v2remove=20261127d) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 规则

- 一篇科普文章一个详情页，从科普首页文章卡、相关阅读进入。文章正文由知识库统一维护，运营改稿后页面随之变化，不用逐篇改前端。
- Demo 为单篇静态示例；正式上线按文章标识取对应内容，参数形式待技术确认。

### 页面结构（自上而下）

| 区块 | 内容 |
| --- | --- |
| 顶栏 | 左返回（回上一页）；中间标题 `减重科普`；右分享 |
| 版头卡 | 分类角签（如 `认识药物减重`）+ 文章标题 + 导语块；导语块显示标签 `导语` 和导语正文 |
| 正文卡 | 按章节分卡；节标题前品牌色短竖条，标题不带编号；每节下是要点条目：品牌色菱形点 + 加粗关键词 + 说明，条目间细分割线 |
| 继续了解 | 标题 `继续了解`；2 条同主题文章链接，点击进入对应详情页 |
| 吸底 | 按钮文案 `免费领取体质评估报告`；阶段 1–2 进首诊问卷（`?state=new`），阶段 3 及以上进疗程随访评估 |

- 分享：调系统分享；不支持时依次尝试复制链接。成功提示 `链接已复制`，失败提示 `复制失败，请长按地址栏复制`，都不支持提示 `当前浏览器不支持分享`。
- 不设置「问 AI 减重助理」「还有疑问」「解决了」入口，也不显示独立审核说明卡。
- 文中提到其他篇目时写全篇名并可点击；被引用的篇目下架后提示 `内容不存在或已下架`，不跳转。

### 视觉基线

- 手机外壳宽 375px；页面底 `#F2F5F6`，卡片白底圆角 8px；主色 `#009BBF`，浅底 `#EDFAFC`，标题 `#1A1A1A`，正文 `#333333`，辅助 `#666666` / `#999999`，分割线 `#E8E8E8`。
- 字体 PingFang SC，正文 14px、行高 1.7；按钮高 40px、圆角 6px、主色底白字。

## 2. 验收

- [ ] 从首页入门卡、文章卡点进来，标题与导语和列表一致
- [ ] 顶栏居中标题 `减重科普`，左右分别为返回和分享；分享按提示原文反馈
- [ ] 版头为分类角签 + 标题 + `导语` 块；正文按章节分卡，节标题无编号，要点用菱形点
- [ ] `继续了解` 显示 2 条同主题文章并可跳转
- [ ] 吸底按钮文案 `免费领取体质评估报告`；阶段 1–2 进首诊问卷，阶段 3 及以上进疗程随访评估
- [ ] 不出现「问 AI 减重助理」「还有疑问」「解决了」和独立审核说明卡
- [ ] 按文章标识取内容，不再所有文章都显示同一篇；已下架篇目提示 `内容不存在或已下架`
