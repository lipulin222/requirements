# 科普文详情页

> 编号 `REQ-WL-EDU-02` ｜ 项目：科学减重（WL）｜ 模块：科普·内容 ｜ 优先级 P1 ｜ 状态：待评审
> Demo：[科普文详情页](https://lipulin222.github.io/health-subscription-demo/edu-article/index.html) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 规则

- 一篇科普文章一个详情页，从科普知识库首页、减重卡「猜你想问」、文内「相关阅读」进入。文章正文由知识库统一维护，页面只负责排版；运营改稿后页面跟着变，不用逐篇改前端。
- Demo 里只有一篇静态示例 `GLP-1 是怎么帮你减重的`：地址上的 `?a=` 参数目前不影响显示，知识库里 15 篇文章都会落到这一页。正式上线要按文章标识取对应内容。

### 页面结构（自上而下）

| 区块 | 内容 |
| --- | --- |
| 顶栏 | 左返回（回上一页）；右分享（调系统分享，不支持时复制链接）；中间不显示标题 |
| 版头 | 文章大标题 + 一句导语；无副标题、无阅读时长、无形态标签 |
| 正文 | 5 张白色卡片，编号 `01`–`05` 配青色章节标题，卡内是带小标题的清单条目 |
| 相关阅读 | 一张卡片，3 条同主题文章，点击进对应文章 |
| 审核说明 | 一张卡片：`审核` 徽标 + `李医生 · 内分泌科 · 主治医师 · 更新 2026.10.15` |

- 页面底部不放吸底按钮（一期不做「问 AI 减重助理」）。
- 正文里提到其他篇目时写全篇名并可点击；被引用的篇目下架后提示 `内容不存在或已下架`，不跳转。
- 手机外壳 375px，页面底 #F2F5F6；卡片白底、圆角 8px；主色 #009BBF；正文 14px、行高 1.7。插图每篇最多 1 张，图上方标「示意图」、图下方左对齐图注（≤30 字）；表格至少 3 行且不超过 3 列才用。

## 2. 验收

- [ ] 从首页入门卡、文章卡点进来，标题与导语和列表一致
- [ ] 顶栏只有返回和分享，中间无标题；分享不成功时复制链接
- [ ] 版头只有大标题和导语；正文 5 张编号卡片；相关阅读 3 条；审核说明原文一致
- [ ] 页面底部无吸底按钮
- [ ] 按文章标识取内容，不再所有文章都显示同一篇
- [ ] 文内篇目引用可跳转；已下架篇目提示 `内容不存在或已下架`
