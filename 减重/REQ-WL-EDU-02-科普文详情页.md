## 1. 页面定位

- 一篇科普文章对应一个详情页，从科普知识库首页（EDU-01）等入口点进。
- 页面内容由知识库统一维护，按固定内容模板渲染；运营改稿后页面随之更新，前台不需要逐页开发文案。

## 2. 页面结构（自上而下）

| 区块 | 规则 |
| --- | --- |
| 顶栏 | 左侧返回按钮；右侧目录图标，点击回科普知识库首页；顶栏中间不显示标题文字 |
| 版头 | 眉标 `科学减重服务`（青色小字）+ 文章大标题（24px 深墨色）+ 导语（13px 灰字，≤30 字，不写阅读指引）+ 底部 1px 分隔细线 |
| 正文 | 每个章节一张白色圆角卡片，卡片间留缝；章节头为青色编号徽标（01 / 02 …）+ 青色章节标题，标题下有细分割线 |
| 审核与说明卡 | 独立一张卡：青色「审核」徽标 + 医生姓名 · 科室 · 职称 · 更新日期；下方一行免责声明 `本篇内容仅供参考，具体情况以你的处方、药品说明书和医生指导为准。` |
| 吸底 | 全宽青色渐变按钮 `问 AI 减重助理`，进入减重 AI 助理对话页 |

## 3. 正文卡片内的元素类型

内容模板支持以下元素，按文章实际内容组合：

| 元素 | 规则 |
| --- | --- |
| 清单条目 | 青色小菱形点 + 条目文字；条目内引导词加粗、破折号后接说明 |
| 名称 + 说明 | 名称行加粗，下方灰字说明；多条之间虚线分隔 |
| 步骤 | 青色圆形序号 + 步骤标题 + 说明，步骤间细分割线 |
| 浅蓝提示块 | 圆角浅蓝底、青色小字的补充提示 |
| 插图 | 图上方左侧「示意图」小标注，图位 16:9，图下方图注（≤30 字，左对齐）；每篇文章最多 1 张，只给有空间关系、顺序、节奏形状的内容配图 |
| 表格 | 至少 3 行且不超过 3 列才使用；表头浅蓝底，手机上不横向滚动 |

## 4. 文内引用跳转

- 正文里提到其他篇目时，写明篇目名（如「见《用药后的反应怎么应对》」），篇目名可点击，跳到对应详情页。
- 被引用的篇目下架后，点击提示 `内容不存在或已下架`，不跳转。
