# 减重卡 · 评估完成状态

> 编号 `REQ-WL-STATUS-05` ｜ 项目：科学减重（WL）｜ 模块：服务状态与卡片 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[线上服务页](https://lipulin222.github.io/online-health-care/weight-companion-ui/online-service.html?stage=2) ｜ 埋点：`REQ-WL-BASE-01`

## 1. 这张卡什么时候出现

用户被灰度到减重卡，已经做完首诊评估问卷、评估报告已生成，但还没支付首诊套餐（没有拿药 / 收货记录）。

## 2. 卡片上显示什么（自上而下）

健康订阅区的头图区与专项标签行见 `REQ-WL-STATUS-02`。

1. **卡头**：
   - 左侧浅绿色方形圆角图标（体重秤图形）。
   - 右侧两行：
     - 第一行：`体重管理`（大号、深色加粗）
     - 第二行：`猜你想问`（青色）+ `· ` + 当前问题（深灰）+ 右侧箭头 `›`
   - 第二行的问题每 2.2 秒换一条，共 5 条，循环播放，前缀不动；具体文案由 @望时 提供后填入。
2. **结论句**：`你的减重评估报告为 [<结论>]`，方括号里的结论取评估报告里的那句话（见 `REQ-WL-PLAN-02`）。
3. **三档刻度条**：
   - 一条横向刻度，等分三段：第一段青色、第二段绿色、第三段橙色。
   - 当前档位上方有一个倒三角指示，落在对应那一段的中间。
   - 三段下方各一行灰字：`无需减重` / `需要减重管理` / `立即减重`。
   - 档位对应：第 1 档 = 无需减重，第 2 档 = 需要减重管理，第 3 档 = 立即减重。
4. **底部两个按钮**，并排等宽、大圆角：
   - 左：`AI减重助理`（浅青底 + 青色描边 + 青色文字）
   - 右：`查看评估报告`（青色实底 + 白字）

## 3. 点击与跳转

| 位置 | 点击后去哪 |
| --- | --- |
| 卡头第二行（`猜你想问 · 问题 ›`） | 科普知识库，定位到当前这条问题对应的文章 |
| `AI减重助理` | AI 减重助理对话页，带购前场景（未开始用药） |
| `查看评估报告` | 减重评估报告 |
