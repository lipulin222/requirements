# 减重卡 · 阶段② 评估完成（消费决策）

> 编号 `REQ-WL-STATUS-05` ｜ 项目：科学减重（WL）｜ 模块：服务状态与卡片 ｜ 优先级 P0 ｜ 状态：待评审
> Demo：[健康订阅区 Demo（阶段②）](https://lipulin222.github.io/health-subscription-demo/online-service.html?stage=2) ｜ 埋点：`REQ-WL-BASE-01`

---

## 1. 这张卡什么时候出现

用户被灰度到减重卡，已经做完首诊评估问卷、评估报告已生成，但还没支付首诊套餐（没有拿药 / 收货记录）。

**30 天转化窗口**：自评估报告生成之日起，30 天内仍未支付首诊套餐的，本卡片退回①购前科普状态（`REQ-WL-STATUS-04`）；期间完成支付则正常进入③进行中。

## 2. 卡片上显示什么（自上而下）

卡头与猜你想问的共用规则见 `REQ-WL-STATUS-04` 第 4 节；本阶段轮播 4 条（见第 3 节）。

1. **结论句**：`你的减重评估报告已生成`（固定文案，不引用报告结论）。
2. **三段刻度条**：
   - 横向等分三段：第 1 段青色渐变、第 2 段绿色、第 3 段橙色。
   - 当前档位那一段正常高亮显示，其余两段弱化（降饱和、变淡）。
   - 三段下方各一行灰字：`无需减重` / `需要减重管理` / `立即减重`。
   - 档位对应：第 1 档 = 无需减重，第 2 档 = 需要减重管理，第 3 档 = 立即减重（口径见 `REQ-WL-PLAN-02`）。
3. **底部一个通栏按钮**：`查看评估报告`（青色实底 + 白字，大圆角）。
   - 「AI减重助理」按钮一期不做。

## 3. 猜你想问（本阶段）

轮播的问题文案**从后台知识库对应的分类里随机拉取**，不在端上写死：

- 本阶段对应知识库中的相应分类，分类与文章的对应关系由后台配置。
- 运营在知识库里增删文章后，轮播内容随之更新。
- 每条问题与其对应文章的链接一并下发，点击进当前这条问题对应的文章。

## 4. 点击与跳转

| 位置 | 点击后去哪 |
| --- | --- |
| 卡头第二行（`猜你想问 · 问题 ›`） | 科普知识库，定位到当前这条问题对应的文章 |
| `查看评估报告` | 减重评估报告 |

## 5. 验收

- [ ] 结论句为固定文案 `你的减重评估报告已生成`
- [ ] 刻度条三段颜色为 青 / 绿 / 橙，当前档位段高亮、其余两段弱化
- [ ] 三档文字为 `无需减重` / `需要减重管理` / `立即减重`，与档位对应正确
- [ ] 猜你想问文案从后台知识库对应分类随机拉取，点击进当前问题对应的文章
- [ ] 底部只有一个通栏按钮 `查看评估报告`，点击进评估报告；无 AI 减重助理按钮
- [ ] 报告生成满 30 天仍未支付首诊套餐，卡片退回购前科普状态；30 天内完成支付正常进入进行中状态
- [ ] 卡片右上角有灰色「切换旧版」文字链（通用规则见 `REQ-WL-STATUS-01` 第 2 节）
- [ ] App 与小程序一致
