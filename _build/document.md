## **一、问卷介绍**

根据以下思维导图，我们对问卷设计和报告生成可能涉及的环节进行拆解。届时用户需要在线填一份10题的问卷（用时约 2 到 3 分钟），系统生成一份评估报告，并进行筛选分流（问卷只做初筛，不替代诊断）。

系统会把用户分到下面三种结果之一：


1. **无适应症：**告诉患者原因，劝退，给饮食和运动建议。
2. **有适应症，且存在合并症/体重大幅度波动（溜溜球体重）**：优先建议线下就诊，如用户坚持线上，也可允许线上服务。
3. **有适应症，无明显慢性疾病**：给饮食、运动、药物建议，进入线上订阅下单页。

### **确认一：问卷的信息量**
1. 药物过敏史、用药史，详细的饮食和生活方式等信息，会在用户进入正式流程后由医生端再采集，您看以上这些问题从筛选目标以及医生端专业需要来看，是否足够？有无其他补充？
2. 在选项中，需不需要加入「不确定」这个选项，比如患者在髓样癌/MEN2、其他病史、备孕怀孕存在不确定如何处理，如果选中了不确定，后续又该如何核实？

## **确认二：哪些情况不适合药物治疗**

下面几种情况，系统会直接告诉患者“目前不适合药物治疗”，说明原因，并给饮食和运动建议。

| <span style="background-color: rgb(242, 242, 242);">情况</span> | <span style="background-color: rgb(242, 242, 242);">拟处理</span> | <span style="background-color: rgb(242, 242, 242);">需要您定的细节</span> | <span style="background-color: rgb(242, 242, 242);">医生意见</span> |
|-----------------------------------------------------------------|--------------------------------------------------------------------|--------------------------------------------------------------------------------|-----------------------------------------------------------------------|
| 本人或直系亲属（父母、兄弟姐妹、子女）被诊断过甲状腺髓样癌或 2 型多发性内分泌腺瘤病 | 不提供药物治疗，给非药物建议 | “直系亲属”的范围是否合适 | 任何甲状腺髓样癌家族史（比如二级以上亲属，祖父母等），都不提供药物，发生率应该非常非常低 |
| 备孕、怀孕或哺乳 | 不提供，结束后经医生评估可再来 | “备孕”指多久内计划怀孕？药物停用后需等多久才可怀孕？ | 需要停药3个月以后才可以开始试孕 |
| 严重胃肠疾病（如胃轻瘫、炎症性肠病、长期严重呕吐或腹泻） | 不提供，建议线下消化科评估 | 包括哪些疾病，哪些程度算“严重” | 长期超过2-3天一次排便，或者炎症性肠病，线上不提供药物。建议线下面诊。<br>长期呕吐腹泻的，应该不太会来咨询这个，如果有提到，也不给药。 |

请问：除了上面3种，还有没有应该直接排除的情况？比如未满18岁，或超过65岁？符不符合不适合治疗的范畴？

## **确认三：哪些情况需要线下就诊或线上沟通**

下面的患者，报告顶部会明确建议先线下就诊。如果患者坚持线上，需要签知情确认，再通过线上提供服务。

| <span style="background-color: rgb(242, 242, 242);">情况</span> | <span style="background-color: rgb(242, 242, 242);">报告会提示患者什么</span> | <span style="background-color: rgb(242, 242, 242);">医生意见</span> |
|-----------------------------------------------------------------|--------------------------------------------------------------------------------------|-----------------------------------------------------------------------|
| 高血压 | 减重通常有助于控压；按医生建议复查血压；不自行调整降压药 |  规律用药，血压控制稳定的，可以线上给药。如果血压仍然没有控制达标140/90以上的，建议转线下 |
| 糖尿病（不用胰岛素） | 注意低血糖；监测血糖；不自行调整降糖药 |  所有糖尿病病史，或者在用任何与血糖相关的药物，最好转线下面诊。<br>口服药也可能涉及增加减重针后，需要调整口服药，如果值班医生不能确定调整方案，就都需要线下面诊评估。 |
| 高血脂、脂肪肝 | 减重有助于改善；定期复查血脂和肝功能 | 甘油三酯超过5.6，低密度脂蛋白胆固醇超过4.9，建议转线下<br>其他规律用药，肝功能正常可以用减重药。血脂高没治疗的，也可以先用减重药。 |
| 痛风或高尿酸血症 | 控酒、少高嘌呤食物；减重宜循序渐进，留意痛风发作 |  尿酸超过540的，或者痛风急性期，建议转线下 |
| 睡眠呼吸暂停 | 减重有助于改善；睡眠症状变化告知医生 |  如果没有戴呼吸机，也可以建议线下就诊评估，但不影响启动药物干预 |
| 关节炎或长期关节疼痛 | 运动选低冲击项目（游泳、骑行、坐姿） |  不影响启动药物干预 |
| 多囊卵巢综合征 | 月经和生育计划请告知医生 |  基本不影响启动减重药干预，需要关注月经情况 |
| 胃食管反流 | 少量多餐，避免暴食和睡前进食 |  关注用药反应 |
| 抑郁症或焦虑症 | 情绪变化及时告知医生 |  如果已经确诊，且在用药的，建议线下评估 |
| 胆结石或胆囊炎 | 减重期间留意右上腹疼痛等症状 | 建议线下评估 |
| 冠心病、心衰或中风 | 心血管风险应优先于减重 | 建议线下评估 |
| 糖尿病且使用胰岛素 | 低血糖风险 | 建议线下评估 |
| 有胰腺炎病史 | 复发风险 | 不建议用药 |
| 糖尿病视网膜病变 | 需先评估眼底 | 建议线下评估 |
| 严重肾脏疾病 | 脱水和肾功能风险，用药受限 | 建议线下评估 |
| 进食障碍（暴食、催吐、过度节食） | 需先评估精神心理状况，避免加重 | 建议线下评估 |

### **确认四：****报告模块**

不同用户模块展示逻辑：

BMI界值：BMI ≥ 28；或 BMI≥24且有体重相关合并症。
- 有慢病合并症用户：慢病包括：高血压、糖尿病、高血脂、脂肪肝、痛风、冠心病或中风、睡眠呼吸暂停、关节炎等。
    - 优先展示慢病管理模块；
    - 增加提醒：慢病指标优先级高于减重，建议线下就诊
    - 输出方案\+线上订阅链接
- 无慢病用户：
    - 饮食调整→运动调整→用药建议
    - 输出方案\+线上订阅链接
- 轻微异常（指标偏高，未达诊断/干预标准）
    - 主流程：饮食、运动、药物
    - 增加提醒：指标偏高，减重或可改善，需随访

## **确认五：老用户拉取已有数据的规则**

原则：只拉本次判断需要的字段，用户逐项确认；易变字段和安全筛查每次重问，不用病历代替。

授权：首次拉取前单独征得用户同意并说明用途；用户可选择“不使用历史记录，手动填写”；拉取失败或字段缺失时，退回新用户问卷的对应题。具体授权方式请与合规确认。

信息展示：医生端默认展示摘要（诊断、用药、近期关键指标），完整看诊记录由医生按需点开，并保留访问日志；不整体展示内科、营养科看诊历史。
